# Vesqen 隐私政策

- 生效日期：2026 年 9 月 26 日
- 最后更新：2026 年 10 月 10 日

本政策说明 Vesqen Android 应用会处理哪些信息、这些信息存放在哪里、应用会通过网络发送什么，以及你联系我们或参加测试时我们会收到什么。本政策适用于我们分发的所有 Vesqen 版本，包括 Google Play 和 GitHub Releases，也适用于 Vesqen 官网。

## 摘要

- Vesqen 播放你设备上的音乐。它没有账号、广告和追踪，也不包含任何第三方统计分析或崩溃报告组件。
- 播放和曲库从不使用网络。你的曲库、收藏、歌单和播放记录都保存在应用的私有存储里，只在你的设备上，我们从不会收到这些信息。
- 从 1.0.0-beta.2 起，GitHub 版 Vesqen 会在三件事上使用网络：每天最多一次的使用统计、你自己选择上传的设备报告，以及检查更新。下文分别说明，每一项都可以关闭。
- 使用统计不带任何安装 ID 或设备 ID，也从不包含你的位置、你的音乐或你听了什么。在欧盟、欧洲经济区、英国、中国大陆和韩国，Vesqen 会先征求你的同意再发送；在其他地区默认开启，第一次打开时的说明页就可以关闭。
- 我们还会收到你主动发给我们的内容，例如支持邮件；参加测试时，还会收到你的邮箱地址。
- Vesqen 官网没有广告，也没有追踪 cookie。官网用不需要 cookie 的 Cloudflare Web Analytics 统计访问量；只有在你同意后，才会用 cookie 记住你的语言。

## 应用在你设备上处理的信息

以下信息在你的设备上处理。除非你自己把它们放进设备报告，否则不会发送给我们或任何其他人。

- **你的曲库。** 在你允许访问的音频文件和文件夹中，Vesqen 会读取文件名、所在文件夹名、文件大小、修改时间、标签（例如标题、艺术家、专辑、专辑艺术家、流派、年份、音轨号和碟号）、内嵌封面，以及音频格式信息（例如编码、采样率、位深、声道数和码率）。
- **你在应用里的使用记录。** 收藏及其顺序、歌单（名称、曲目、顺序以及创建和修改时间）、每首歌的播放次数和最近播放时间、当前播放队列和播放位置，以及你的设置。
- **你的播放链路。** 为了显示 Chain 页面和运行严格 USB 输出，Vesqen 会读取 Android 提供的音频路由信息：当前输出设备的名称和类型（包括已连接的蓝牙音频设备），以及 USB 音频设备的厂商 ID、产品 ID、名称、USB 描述符版本和支持的音频格式。Vesqen 不会申请直接访问 USB 设备。
- **输出验证记录。** 如果你导入一份验证记录文件，Vesqen 会把它保存在私有存储中。为判断是否显示 `BIT-PERFECT VERIFIED`，Vesqen 会把记录与你当前的配置进行比对：已安装应用的版本和安装包哈希值、手机的厂商、型号和 Android 版本、在本机计算出的系统版本指纹（Build fingerprint）哈希值、已连接的 USB 音频设备，以及正在播放的音频格式。
- **最近的错误。** Vesqen 会记下最近的播放错误、严格 USB 输出停止的原因，以及 Android 关闭应用时给出的原因，最多保留最近 7 天内的 100 条。对于播放失败的歌曲，会记下它的格式和文件名。这份记录只是为了让你可以选择把它放进设备报告。
- **你所在的地区。** 为了判断发送使用统计前是否需要先征求同意，Vesqen 会读取手机语言设置里的地区，以及 SIM 卡和移动网络的国家代码。这不需要任何权限，判断结果只在设备上使用，不保存也不发送。

Vesqen 从不修改或删除你的音乐文件。

## 权限

| 权限 | 用途 |
| --- | --- |
| 读取音频文件（Android 13 及以上为 `READ_MEDIA_AUDIO`；Android 12L 及以下为 `READ_EXTERNAL_STORAGE`） | 查找并播放你设备上的音乐。 |
| 你在系统选择器中授权的文件夹访问 | 从你选择的文件夹中读取音乐。该访问为只读，你可以随时移除文件夹。 |
| 通知（`POST_NOTIFICATIONS`） | 在播放时显示播放控制。 |
| 媒体播放前台服务和唤醒锁 | 在熄屏或 Vesqen 处于后台时继续播放。 |
| 修改音频设置（`MODIFY_AUDIO_SETTINGS`） | 在你开启严格 USB 输出时，请求 Android 的 bit-perfect USB 输出模式。 |
| 网络访问（`INTERNET`） | 用于下文所述的使用统计、上传设备报告和检查更新。播放和曲库从不使用网络。 |
| 网络状态（`ACCESS_NETWORK_STATE`） | 发送使用统计前，确认当前有可用的网络连接。Vesqen 使用的 Google Media3 播放库也声明了这项权限。 |
| 安装应用（`REQUEST_INSTALL_PACKAGES`） | 安装你在 Vesqen 里下载的更新。每次安装都由 Android 请你确认。 |
| USB 主机（可选硬件功能） | 识别 USB 音频设备。不支持 USB 主机的手机仍然可以安装 Vesqen。 |

只有读取音乐是必需的。即使你拒绝通知或文件夹访问，Vesqen 仍然可以播放它能读取到的音乐。Vesqen 不申请位置、通讯录、电话、相机、麦克风或蓝牙权限。

## 信息何时会离开应用

- **Android 媒体控件。** 播放时，Vesqen 会把当前曲目的标题、艺术家、专辑、封面和播放进度提供给 Android，用于通知栏和锁屏的播放控制。Android 可能把这些信息传给你连接或授权的设备和服务，例如蓝牙车机、手表或语音助手。只有 Android 系统组件，以及你授权过读取通知或控制媒体播放的应用（例如手表的配套应用），才能连接 Vesqen 的播放会话；手机上的其他应用无法连接。
- **换到新手机时。** Vesqen 不会把它的数据迁移到新手机。你的曲库、收藏、歌单、播放次数和最近播放时间、播放队列、设置和输出验证记录都只保存在原来的手机上；在新手机上，你需要重新允许 Vesqen 读取音频文件，或重新添加音乐文件夹。Vesqen 关闭了 Android 云备份，因此这些数据不会备份到 Google 云端硬盘；它也要求 Android 在设备间迁移时不复制这些数据。个别手机厂商的换机工具可能不遵守这项要求，仍会把应用数据复制到新手机。
- **网络功能。** 应用只在使用统计、上传设备报告和检查更新时使用网络，包括它们各自需要的状态文件和下载。接下来三节分别说明。

## 使用统计

- **发送什么。** 每天最多一次，在你打开 Vesqen 时发送一条消息，内容只有：应用版本和分发渠道；Android 版本、手机厂商、型号和系统版本名称；在 Android 能判断时，已连接的 USB 音频设备是否支持 Android 的 bit-perfect 模式；最近 7 天里是否连接过 USB 音频设备；以及这是不是今天、本周和本月的第一条。
- **从不发送什么。** 不带安装 ID 或设备 ID，不涉及账号，不包含位置或国家，也不包含你的音乐、文件名或你听了什么。
- **留在手机上的。** Vesqen 会记住上次发送统计的时间，以及上次检测到 USB 音频设备的时间。它需要这两个时间来保证每天最多发送一次，并填写上面的内容。
- **发到哪里。** 消息发到我们运行在 Cloudflare 上的统计服务。服务把它计入每天的总数，不保存消息本身，也不记录 IP 地址。Cloudflare 作为我们的服务商，会为传送请求和保护服务处理你的 IP 地址。服务的回复里可能附带最新的版本信息，Vesqen 用它来检查更新。
- **你的选择。** 在欧盟、欧洲经济区、英国、中国大陆和韩国，以及 Vesqen 读不出国家时，它会先征求你的同意，两个选项都不预先选中；你不同意就什么都不发送。在其他地区默认开启：第一次打开时的说明页会解释统计内容并提供开关，离开这一页之前不会发送任何内容。你可以随时在"设置 → 隐私与数据 → 使用统计"里关闭，关闭后立即停止发送。已经发送的统计已计入与你无关联的每日总数，无法单独删除。
- **暂停。** 在发送统计或上传报告之前，Vesqen 会读取官网上的一个小状态文件，确认我们有没有暂停这项服务，最多每 10 分钟读取一次。关闭统计后，只有在你上传报告时才会读取。这个请求除了所有网络请求都会带有的信息（例如你的 IP 地址），不包含任何关于你的内容。

## 设备报告

- **生成报告。** 在"设置 → 隐私与数据 → 导出设备报告"里，你可以生成一份报告，帮我们排查问题。报告总会包含应用版本和构建类型、手机厂商、型号、Android 版本、系统版本名称以及生成时间。你可以选择是否加入：音频输出能力（包括 USB 音频设备的厂商 ID、产品 ID 和支持的格式）；链路页上的数值（例如格式、解码器、缓冲、电池和处理器读数）；上文所述的最近错误；播放失败的歌曲的格式；以及单独选择是否加入它们的文件名。蓝牙设备名称、输出路由名称、解码器名称和处理器型号会被去掉。报告离开应用之前，你会看到完整内容。
- **发送报告。** 你可以把报告分享给你选择的应用、通过邮件发给我们，或者上传。分享和邮件通过你选择的应用发送。Vesqen 会在缓存里保留最近的报告文件以便分享，并在你下次分享时删除超过一天的文件。
- **上传报告。** 上传会把报告发到我们在 Cloudflare 上的服务。服务保存报告，同时记下一个随机的回执编号和收到的时间，不记录 IP 地址。除非你把回执编号发给我们，否则报告不会和你关联。上传的报告保留 7 天后删除。如需提前删除，请把回执编号发邮件给我们。

## 检查更新

- **检查。** GitHub 版 Vesqen 可以检查新版本：在你打开应用时每天最多自动检查一次，你点"检查更新"时也会检查。检查时会从我们的官网 vesqen.sumirenokai.com 读取一个版本文件，官网由 Cloudflare 托管。开启使用统计时，版本信息也可能随统计的回复一起送达，不再单独请求。检查不带任何标识，只有所有网络请求都会带有的信息，例如你的 IP 地址。你可以在"设置 → 更新 → 自动检查更新"里关闭自动检查。
- **下载。** 只有在你点"下载"时，Vesqen 才会下载更新。文件来自 GitHub，这次下载适用 GitHub 的隐私声明。安装之前，Vesqen 会核对文件的 SHA-256 和签名证书，Android 也会请你确认。下载的文件在交给 Android 安装程序后，或者更新失败时，就会被删除。
- **其他来源。** 如果 Vesqen 是从 Google Play 安装的，它不会去 GitHub 检查更新。如果由其他应用（例如 F-Droid 客户端）管理 Vesqen 的更新，自动检查默认关闭。

## 我们会收到的信息

- **你发给我们的邮件。** 如果你联系我们，我们会收到你的邮箱地址和邮件内容，包括你附上的设备报告，仅用于回复你。发到 sumirenokai.com 邮箱的邮件，会经 Cloudflare 的邮件转发，保存在我们的 Microsoft Outlook 邮箱里。
- **统计和报告。** 使用统计我们只能看到每天的总数。设备报告我们能看到你上传的报告，在保留的 7 天内。
- **封闭测试。** 如果你参加 Vesqen 在 Google Play 上的测试，你的 Google 账号邮箱会被加入 Google Play 管理中心里这次测试的测试者名单，Google 据此向你开放测试版。你通过 Google Play 发来的反馈，我们也能看到。这些信息仅用于开展测试。
- **应用内购买。** Vesqen 目前没有应用内购买。以后的版本如果加入，我们会在该版本发布前更新本政策。
- **Google Play 统计数据。** Google 可能向我们提供关于安装量和应用稳定性的汇总统计，包括来自选择与 Google 共享使用情况和诊断数据的用户的崩溃报告。我们仅用它们来发现和修复问题。
- **GitHub 下载。** 如果你从 GitHub 下载 Vesqen，无论是在浏览器里还是通过应用的检查更新，该下载都适用 GitHub 的隐私声明。

## Vesqen 官网

Vesqen 官网（vesqen.sumirenokai.com）托管在 Cloudflare 上，没有账号、表单和广告。应用读取的版本文件和状态文件也由官网提供。

- **提供网页。** 为了发送网页和文件并防止滥用，Cloudflare 会处理每一次访问请求，其中包括你的 IP 地址、浏览器信息和所访问页面的地址。Cloudflare 代我们处理这些信息，也可能按它的隐私政策，用这些网络数据保护它自己的服务。Cloudflare 会向我们展示汇总统计，例如各国家或地区的请求数。我们不会用这些信息识别访客。
- **选择语言。** 打开首页时，官网按浏览器的语言设置显示中文或英文；判断不出来时，再参考 Cloudflare 根据 IP 地址估计的国家或地区。每次访问都会重新判断，不保存任何信息。
- **访问统计。** 官网用 Cloudflare Web Analytics 统计访问量。每个页面上有一段 Cloudflare 的小脚本，会上报页面地址、你从哪个页面过来，以及页面加载的快慢；Cloudflare 会再加上国家或地区、浏览器和设备类型。这段脚本不使用 cookie，也不在你的浏览器里存储任何信息。我们只能看到汇总统计，Cloudflare 最多向我们展示六个月的数据。通过 Cloudflare 位于欧盟、欧洲经济区和英国的数据中心访问时，不会被统计。
- **Cookie。** 第一次访问时，官网会询问能否记住你的语言。官网最多设置两个 cookie，都不用于追踪：

| Cookie | 用途 | 保存时间 |
| --- | --- | --- |
| `vesqen-consent` | 记住你接受还是拒绝了 cookie，免得反复询问。 | 6 个月 |
| `vesqen-lang` | 记住你的语言。只在你接受后设置。 | 6 个月 |

你可以随时在每页底部的"Cookie 设置"里更改选择。拒绝后，官网会删除 `vesqen-lang`。如果 Cloudflare 需要确认访问不是由自动程序发起的，它可能会设置自己的安全 cookie，例如 `__cf_bm` 或 `cf_clearance`。这些 cookie 是 Cloudflare 运行服务所必需的，不会用来追踪你。应用和官网都不会跨网站或跨应用追踪你，所以浏览器的"请勿追踪"（Do Not Track）设置在这里不会改变什么。

## 保留和删除

| 信息 | 保留时间 |
| --- | --- |
| 你设备上应用里的数据 | 直到你删除 |
| 你设备上的最近错误 | 7 天，最多 100 条 |
| 使用统计 | 每天的总数保留 90 天 |
| 上传的设备报告 | 7 天 |
| 支持邮件 | 对话结束后最多 12 个月 |
| 测试者名单 | 测试结束后最多 2 个月 |

- **你设备上的数据。** 移除某个音乐文件夹会删除它对应的曲库记录；你也可以在应用里删除歌单、取消收藏。要删除应用的全部数据，可以在 Android 设置 → 应用 → Vesqen → 存储中清除存储空间，或者卸载 Vesqen。

- **提前删除。** 如果你提出要求，我们会更早删除邮件、测试者名单中的记录和上传的报告。

## 安全

- 你设备上的数据保存在 Vesqen 的私有存储中，受 Android 应用沙盒保护。应用只会发送本政策所述的网络消息。
- 所有网络请求都使用 HTTPS。Vesqen 只会在核对 SHA-256、并确认签名密钥与已安装的应用相同之后，才安装更新。
- Vesqen 对你的音乐文件夹只有只读权限。
- 我们的统计和报告服务不保存 IP 地址，也不保存请求日志。
- 我们的支持邮箱开启了两步验证。

## 儿童

Vesqen 并非面向儿童设计，我们不会有意收集儿童的个人信息。如果你认为有儿童向我们发送了个人信息，请联系我们，我们会将其删除。

## 你的选择和权利

- **在应用里。** 如上文所述，Vesqen 保存在你设备上的一切都由你控制。你可以在"设置 → 隐私与数据 → 使用统计"里关闭使用统计，在"设置 → 更新"里关闭自动检查更新。是否上传报告始终由你决定。
- **你的权利。** 你可以要求我们确认是否持有关于你的信息，查阅、复制、更正、补充或删除这些信息，解释我们如何使用、与谁共享这些信息，限制或反对我们使用这些信息，或者撤回同意。请发邮件到 vesqen@sumirenokai.com，我们会在 15 个工作日内回复。
- **投诉。** 你可以向同一个地址投诉。我们会在 30 天内确认收到投诉，并告诉你处理结果。你也可以向你所在地的数据保护监管机构投诉，例如英国的信息专员办公室（ICO）或巴西的国家数据保护局（ANPD）。
- **法律依据。** 在适用欧盟或英国数据保护法律的情况下，使用统计、语言 cookie 和你上传的报告基于你的同意。在中国大陆和韩国，使用统计同样基于你的同意。在巴西法律适用于使用统计的情况下，统计基于我们了解 Vesqen 在哪些手机和 Android 版本上运行的正当利益，你可以随时关闭统计来表示反对。检查更新、回复你、开展测试，以及保持官网和我们的服务正常运行和安全，基于我们在这些方面的正当利益。
