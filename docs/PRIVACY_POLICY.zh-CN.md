# Vesqen 隐私政策

- 生效日期：2026 年 9 月 26 日
- 最后更新：2026 年 11 月 1 日

本政策说明 Vesqen Android 应用会处理哪些信息、相关信息的存储位置、应用通过网络发送的信息，以及您联系我们或参加测试时我们接收的信息。本政策适用于我们分发的所有 Vesqen 版本，包括 Google Play 和 GitHub Releases，也适用于 Vesqen 官网。

## 摘要

- Vesqen 播放您设备上的音乐。本应用不设账号，不含广告或追踪功能，也不包含任何第三方统计分析或崩溃报告组件。
- 播放和曲库从不使用网络。您的曲库、收藏、歌单和播放记录均保存在您设备上的应用私有存储中，不会发送给我们。
- 从 1.0.0-beta.2 起，Vesqen 通过网络提供以下功能：每天最多一次的使用统计，以及您选择上传的设备报告。GitHub 版还会检查更新。下文分别说明，每一项都可以关闭。
- 使用统计不包含任何安装 ID 或设备 ID，也从不包含您的位置、您的音乐或您的收听内容。在欧盟、欧洲经济区、英国、中国大陆和韩国，Vesqen 会先征求您的同意再发送；在其他地区默认开启，可在首次启动时的说明页面关闭。
- 我们还会收到您主动向我们提供的内容，例如支持邮件；参加测试时，还会收到您的邮箱地址。
- Vesqen 官网没有广告，也没有追踪 Cookie。官网使用无需 Cookie 的 Cloudflare Web Analytics 统计访问量；仅在您同意后，才使用 Cookie 记忆您的语言选择。

## 应用在您设备上处理的信息

以下信息在您的设备上处理。除非您主动将相关信息纳入设备报告，否则不会向我们或任何第三方发送。

- **您的曲库。** 在您允许访问的音频文件和文件夹中，Vesqen 会读取文件名、所在文件夹名、文件大小、修改时间、标签（例如标题、艺术家、专辑、专辑艺术家、流派、年份、音轨号和碟号）、内嵌封面，以及音频格式信息（例如编码、采样率、位深、声道数和码率）。
- **应用内使用记录。** 收藏及其顺序、歌单（名称、曲目、顺序以及创建和修改时间）、每首歌的播放次数和最近播放时间、当前播放队列和播放位置，以及您的设置。
- **您的播放链路。** 为显示 Chain 页面并执行严格 USB 输出，Vesqen 会读取 Android 提供的音频路由信息：当前输出设备的名称和类型（包括已连接的蓝牙音频设备），以及 USB 音频设备的厂商 ID、产品 ID、名称、USB 描述符版本和支持的音频格式。Vesqen 不会申请直接访问 USB 设备。在 Android 13 及以上，如果您允许“附近的设备”权限，Vesqen 还会接收 Android 报告的已连接耳机或音箱的蓝牙编码（例如 96 kHz 的 LDAC），并在 Chain 页面显示。相关信息仅保留在您的手机上，并在设备断开后清除。
- **输出验证记录。** 如果您导入一份验证记录文件，Vesqen 会将其保存在私有存储中。为判断是否显示 `BIT-PERFECT VERIFIED`，Vesqen 会将记录与您当前的配置进行比对：已安装应用的版本和安装包哈希值、手机的厂商、型号和 Android 版本、在本机计算出的系统版本指纹（Build fingerprint）哈希值、已连接的 USB 音频设备，以及正在播放的音频格式。
- **最近的错误。** Vesqen 会记录最近的播放错误、严格 USB 输出停止的原因，以及 Android 提供的应用关闭原因，最多保留最近 7 天内的 100 条。对于播放失败的歌曲，会记录该歌曲的格式和文件名。该记录用于供您选择是否纳入设备报告。
- **崩溃记录。** 如果 Vesqen 因未处理的错误而崩溃，应用会记录错误类型和导致错误的代码位置（类名、方法名和行号），包括引发该错误的底层错误，以及应用版本和出错时间。错误附带的说明文字可能含有文件路径或歌名，Vesqen 从不记录。它最多保留最近 3 次崩溃，最长 7 天；您上传报告之后或选择“不用了”后删除。分享或通过邮件发送后，Vesqen 无法确认最终是否发送成功，因此会保留至 7 天期限届满。
- **您所在的地区。** 为了判断发送使用统计前是否需要先征求同意，Vesqen 会读取手机语言设置中的地区、SIM 卡和移动网络的国家代码，以及时区设置对应的国家。时区只会让 Vesqen 先征求同意，不会因此默认开启统计。此过程无需任何权限，判断结果只在设备上使用，不保存也不发送。

Vesqen 从不修改或删除您的音乐文件。

## 权限

| 权限 | 用途 |
| --- | --- |
| 读取音频文件（Android 13 及以上为 `READ_MEDIA_AUDIO`；Android 12L 及以下为 `READ_EXTERNAL_STORAGE`） | 查找并播放您设备上的音乐。 |
| 您在系统选择器中授权的文件夹访问 | 从您选择的文件夹中读取音乐。该访问为只读，您可以随时移除文件夹。 |
| 通知（`POST_NOTIFICATIONS`） | 在播放时显示播放控制。 |
| 媒体播放前台服务和唤醒锁 | 在熄屏或 Vesqen 处于后台时继续播放。 |
| 修改音频设置（`MODIFY_AUDIO_SETTINGS`） | 在您开启严格 USB 输出时，请求 Android 的 bit-perfect USB 输出模式。 |
| 附近的设备（`BLUETOOTH_CONNECT`，Android 13 及以上） | 可选，只在您选择显示蓝牙编码时才申请。只用于接收 Android 报告的编码。Vesqen 不会搜索、配对或连接蓝牙设备。 |
| 网络访问（`INTERNET`） | 用于下文所述的使用统计、上传设备报告，以及 GitHub 版的检查更新。播放和曲库从不使用网络。 |
| 网络状态（`ACCESS_NETWORK_STATE`） | 发送使用统计前，确认当前有可用的网络连接。Vesqen 使用的 Google Media3 播放库也声明了这项权限。 |
| 安装应用（`REQUEST_INSTALL_PACKAGES`） | 仅 GitHub 版有，用于安装您在 Vesqen 中下载的更新。每次安装均由 Android 请求您确认。 |
| USB 主机（可选硬件功能） | 识别 USB 音频设备。不支持 USB 主机的手机仍然可以安装 Vesqen。 |

只有读取音乐是必需的。即使您拒绝通知、文件夹访问或“附近的设备”权限，Vesqen 仍然可以播放可读取的音乐。Vesqen 不申请位置、通讯录、电话、相机或麦克风权限。

## 信息向应用外部提供的情形

- **Android 媒体控件。** 播放时，Vesqen 会将当前曲目的标题、艺术家、专辑、封面和播放进度提供给 Android，用于通知栏和锁屏的播放控制。Android 可能将这些信息提供给您连接或授权的设备和服务，例如蓝牙车机、手表或语音助手。只有 Android 系统组件，以及您授权过读取通知或控制媒体播放的应用（例如手表的配套应用），才能连接 Vesqen 的播放会话；手机上的其他应用无法连接。
- **更换手机。** Vesqen 不会将应用数据迁移至新手机。您的曲库、收藏、歌单、播放次数和最近播放时间、播放队列、设置和输出验证记录都只保存在原手机上；在新手机上，您需要重新允许 Vesqen 读取音频文件，或重新添加音乐文件夹。Vesqen 关闭了 Android 云备份，因此这些数据不会备份到 Google 云端硬盘；它也要求 Android 在设备间迁移时不复制这些数据。个别手机厂商的换机工具可能不遵守这项要求，仍可能将应用数据复制至新手机。
- **支持开发。** GitHub 版在“关于”页面提供“支持开发”链接，也会偶尔询问您是否愿意支持 Vesqen。两者均仅在浏览器中打开我们的 Buy Me a Coffee 页面，Vesqen 本身不发送任何内容。为确定提示时机，应用在您的设备上记录提示次数、上次询问的时间，以及您是否选择了不再提示。Google Play 版均不包含上述功能。
- **网络功能。** 应用只在使用统计、上传设备报告和检查更新（仅 GitHub 版）时使用网络，包括它们各自需要的状态文件和下载。接下来三节分别说明。

## 使用统计

- **发送的信息。** 每天最多一次，在您打开 Vesqen 时发送一条消息，内容只有：应用版本和分发渠道；Android 版本、手机厂商、型号和系统版本名称；在 Android 能判断时，已连接的 USB 音频设备是否支持 Android 的 bit-perfect 模式；最近 7 天里是否连接过 USB 音频设备；以及这是否为当天、本周和本月的首次消息。
- **不发送的信息。** 不带安装 ID 或设备 ID，不涉及账号，不包含位置或国家，也不包含您的音乐、文件名或您的收听内容。
- **设备上保存的信息。** Vesqen 会记住上次发送统计的时间，以及上次检测到 USB 音频设备的时间。上述时间用于限制每天最多发送一次，并生成前述统计字段。
- **接收方。** 消息发送至我们部署在 Cloudflare 上的统计服务。服务将消息计入每日汇总，不保存消息本身，也不保存 IP 地址。Cloudflare 作为我们的服务商，会为传送请求和保护服务处理您的 IP 地址，并保留下文“Cloudflare 的请求记录”中说明的记录。服务响应中可能附带最新的版本信息，GitHub 版使用该信息检查更新。
- **您的选择。** 在欧盟、欧洲经济区、英国、中国大陆和韩国，以及 Vesqen 无法确定国家时，它会先征求您的同意，两个选项都不预先选中；未经您同意不发送任何统计。在其他地区默认开启：第一次打开时的说明页会解释统计内容并提供开关，离开该页面之前不会发送任何内容。您可以随时在"设置 → 隐私与数据 → 使用统计"中关闭，关闭后立即停止统计发送。已经发送的统计已计入与您无关联的每日总数，无法单独删除。
- **服务可用性检查。** 在发送统计或上传报告之前，Vesqen 会读取官网上的服务状态文件，确认该服务是否已暂停，最多每 10 分钟读取一次。关闭统计后，只有在您上传报告时才会读取。该请求除网络通信通常包含的信息（例如您的 IP 地址），不包含任何关于您的内容。

## 设备报告

- **生成报告。** 在"设置 → 隐私与数据 → 导出设备报告"中，您可以生成用于协助排查问题的报告。报告必定包含应用版本和构建类型、手机厂商、型号、Android 版本、系统版本名称以及生成时间。您可以选择是否加入：音频输出能力（包括 USB 音频设备的厂商 ID、产品 ID 和支持的格式）；链路页上的数值（例如格式、解码器、缓冲、电池和处理器读数，以及 Android 报告的蓝牙编码）；上文所述的最近错误；上文所述的崩溃记录；播放失败的歌曲的格式；以及单独选择是否加入它们的文件名。蓝牙设备名称、输出路由名称、解码器名称和处理器型号会被移除。报告离开应用之前，您可以查看完整内容。
- **崩溃之后。** 如果 Vesqen 上次崩溃或无响应，下次打开时会询问一次是否发送报告。选择“查看并发送”会打开“导出设备报告”，并预先选中崩溃记录和最近的错误；您可在该页面查看完整报告，再选择上传、分享或通过邮件发送。选择“不用了”会删除保存的崩溃记录。只有您选择发送时，报告才会发出。
- **发送报告。** 您可以把报告分享给您选择的应用、通过邮件发给我们，或者上传。分享和邮件通过您选择的应用发送。Vesqen 会在缓存中保留最近的报告文件以便分享，并在您下次分享时删除超过一天的文件。
- **上传报告。** 上传会把报告发到我们在 Cloudflare 上的服务。服务保存报告，同时记录随机回执编号与接收时间，不保存 IP 地址。除非您把回执编号发给我们，否则报告不会与您关联。上传的报告保留 7 天后删除。如需提前删除，请通过邮件向我们提供回执编号。

## 检查更新

- **检查。** GitHub 版 Vesqen 可以检查新版本：在您打开应用时每天最多自动检查一次，您点击"检查更新"时也会检查。检查时会从我们的官网 vesqen.sumirenokai.com 读取一个版本文件，官网由 Cloudflare 托管。开启使用统计时，版本信息也可能随统计响应一并返回，不再单独请求。检查不包含任何标识，只有所有网络请求都会带有的信息，例如您的 IP 地址。您可以在"设置 → 更新 → 自动检查更新"中关闭自动检查。
- **下载。** 只有在您点击"下载"时，Vesqen 才会下载更新。文件来自 GitHub，该下载适用 GitHub 的隐私声明。安装之前，Vesqen 会核对文件的 SHA-256 和签名证书，Android 也会请求您确认。未通过核对的文件会被删除；通过核对的文件保留在 Vesqen 的私有存储中，直到您下次打开应用，以便在取消安装后重试时无需重新下载。
- **其他来源。** Google Play 版没有自己的更新检查，由 Google Play 负责更新。如果由其他应用（例如 F-Droid 客户端）管理 GitHub 版的更新，自动检查默认关闭。

## 我们会收到的信息

- **您发给我们的邮件。** 如果您联系我们，我们会收到您的邮箱地址和邮件内容，包括您附上的设备报告，仅用于回复您。发到 sumirenokai.com 邮箱的邮件，会经 Cloudflare 的邮件转发，保存在我们的 Microsoft Outlook 邮箱中。
- **统计和报告。** 使用统计我们仅能查看每日汇总。我们可在 7 天保留期限内查看您上传的设备报告。
- **封闭测试。** 如果您参加 Vesqen 在 Google Play 上的测试，您的 Google 账号邮箱会被加入 Google Play 管理中心中这次测试的测试者名单，Google 据此向您开放测试版。您通过 Google Play 发来的反馈，我们亦可查看。这些信息仅用于开展测试。
- **应用内购买。** Vesqen 目前没有应用内购买。以后的版本如果加入，我们会在该版本发布前更新本政策。
- **通过 Buy Me a Coffee 的支持。** 如果您在 Buy Me a Coffee 上支持 Vesqen，按照它的隐私政策，我们可查看您的姓名或昵称、邮箱、留言，以及金额和日期。付款由 Stripe 处理，我们无法获取您的卡号。默认情况下，您的姓名和留言也会显示在我们的 Buy Me a Coffee 页面上，您可以在 Buy Me a Coffee 的设置中更改。支持不会解锁应用中的任何功能。上述信息仅用于记录支持，以及回复您的来信。
- **Google Play 统计数据。** Google 可能向我们提供关于安装量和应用稳定性的汇总统计，包括来自选择与 Google 共享使用情况和诊断数据的用户的崩溃报告。我们仅用它们来发现和修复问题。
- **GitHub 下载。** 如果您从 GitHub 下载 Vesqen，无论是在浏览器中还是通过应用的检查更新，该下载都适用 GitHub 的隐私声明。

## Vesqen 官网

Vesqen 官网（vesqen.sumirenokai.com）托管在 Cloudflare 上，没有账号、表单和广告。应用读取的版本文件和状态文件也由官网提供。

- **提供网页。** 为了发送网页和文件并防止滥用，Cloudflare 会处理每一次访问请求，其中包括您的 IP 地址、浏览器信息和所访问页面的地址。Cloudflare 代我们处理这些信息，也可能按它的隐私政策，用这些网络数据保护它自己的服务。Cloudflare 会向我们展示统计数据，例如各国家或地区的请求数，以及下文“Cloudflare 的请求记录”中说明的抽样请求记录。我们不会用这些信息识别访客。
- **选择语言。** 打开首页时，官网按浏览器的语言设置显示英文、简体中文、繁体中文或日语；无法确定时，再参考 Cloudflare 根据 IP 地址估计的国家或地区。每次访问都会重新判断，不保存任何信息。
- **访问统计。** 官网用 Cloudflare Web Analytics 统计访问量。每个页面上包含 Cloudflare 脚本，会上报页面地址、来源页面，以及页面加载性能；Cloudflare 会补充国家或地区、浏览器和设备类型。这段脚本不使用 Cookie，也不在您的浏览器中存储任何信息。我们仅能查看汇总统计，Cloudflare 最多向我们展示六个月的数据。通过 Cloudflare 位于欧盟、欧洲经济区和英国的数据中心访问时，不会被统计。
- **Cookie。** 第一次访问时，官网会询问能否记忆您的语言选择。官网最多设置两个 Cookie，都不用于追踪：

| Cookie | 用途 | 保存时间 |
| --- | --- | --- |
| `vesqen-consent` | 记录您接受或拒绝 Cookie 的选择，避免重复询问。 | 6 个月 |
| `vesqen-lang` | 记忆您的语言选择。仅在您接受后设置。 | 6 个月 |

您可以随时在每页底部的"Cookie 设置"中更改选择。拒绝后，官网会删除 `vesqen-lang`。如果 Cloudflare 需要确认访问不是由自动程序发起的，它可能会设置自己的安全 Cookie，例如 `__cf_bm` 或 `cf_clearance`。这些 Cookie 是 Cloudflare 运行服务所必需的，不会用来追踪您。应用和官网都不会跨网站或跨应用追踪您，因此浏览器的"请勿追踪"（Do Not Track）设置不会改变上述处理方式。

## 安全

- 您设备上的数据保存在 Vesqen 的私有存储中，受 Android 应用沙盒保护。应用只会发送本政策所述的网络消息。
- 所有网络请求都使用 HTTPS。Vesqen 只会在核对 SHA-256、并确认签名密钥与已安装的应用相同之后，才安装更新。
- Vesqen 对您的音乐文件夹只有只读权限。
- 我们的统计和报告服务不会把 IP 地址或请求日志写入其数据库。Cloudflare 自己的请求记录，见“服务商和跨境传输”中的“Cloudflare 的请求记录”。
- 我们的支持邮箱开启了两步验证。
