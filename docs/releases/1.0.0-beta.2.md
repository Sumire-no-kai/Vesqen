**English** · [中文](#中文)

The second public beta of Vesqen, an offline music player for Android. It plays the music stored on your phone, needs no account, and shows the path each track takes from the file to your headphones.

## Upgrading from beta.1

beta.1 can't update itself. Download `Vesqen-1.0.0-beta.2.apk` below and install it over beta.1: it is signed with the same key, so your library, playlists, favorites and settings stay. Don't uninstall first, because that deletes them. From this version on, Vesqen can find and install updates itself.

## What's new

- **A new look.** Library, Now, Chain, Settings, the queue, track details and About are redrawn on paper tones with a serif for titles, in light and dark. Now takes the whole screen while a song plays, and the launch screen draws the refined app icon.
- **The Chain page reads in one go.** It follows the sound in five steps, from the file to the output, and says whether Vesqen's own part changed the audio. For Bluetooth, it shows the two parts separately: Vesqen's part, and the system's Bluetooth encoding, which is lossy or unknown.
- **In-app updates.** Settings → Updates checks for new versions at most once a day, or when you tap Check for updates. Vesqen downloads only when you ask, checks the file's SHA-256 and signature, and Android asks you to confirm the install.
- **Device reports.** Settings → Privacy & data → Export device report builds a report for a problem you want us to look at. You pick what goes in, see the whole report first, and then share it, email it or upload it.
- **Usage statistics.** Once a day at most, with no ID attached. In the EU, the EEA and the UK, Vesqen asks first. Elsewhere it is on by default and the first screen lets you turn it off.
- **Open-source licenses** for every library in the app, under Settings.
- **Fixes:** an unknown artist no longer shows as `<unknown>` (#32); the Chain page no longer presents older values as the current path (#33); strict USB no longer shows a failure dialog right after a cold start (#34); strict output recovers correctly after an interrupted session.

## Install

- Requirements: Android 8.0 or later. Strict USB output needs Android 14 or later and a compatible USB DAC.
- Download `Vesqen-1.0.0-beta.2.apk` below. SHA-256: `发布时填写`
- Application signing certificate SHA-256: `74:3E:96:FC:B7:1D:C5:81:88:49:68:19:A0:01:A2:7C:D8:8D:90:91:62:C5:AE:92:9C:87:BF:A2:9A:B8:62:93`. Check it with `apksigner verify --print-certs`.

## Known limitations

- No phone and DAC combination has been verified bit-perfect yet, so no `BIT-PERFECT VERIFIED` record exists.
- Strict USB output hasn't been confirmed with a real DAC yet. Many phones don't offer Android's bit-perfect path, even on Android 14 and later. None of the Android 14+ phones we tested (vivo and iQOO, on Android 15 and 16) offer it, so strict mode stops there and tells you why. System output still plays through USB DACs and speakers as usual.
- Android 13 and earlier don't provide the official bit-perfect mixer API, so strict USB output isn't available there.
- Bluetooth is never bit-perfect. The Chain page can say that Vesqen's part left the audio unchanged; the phone still re-encodes it for Bluetooth.
- Vesqen doesn't move its data to a new phone. Favorites, playlists and settings stay on the old phone.
- If Android stops Vesqen in the background, the queue comes back when you open the app again. Resuming straight from headphone buttons isn't supported yet.
- Long listening sessions, foldables, high refresh rates and complete TalkBack coverage are still being tested.

## Privacy

Playback and your library still never use the network. This version is the first to use it, for three things you can turn off: usage statistics, device reports you choose to upload, and update checks. The [privacy policy](https://vesqen.sumirenokai.com/privacy/) lists what each one sends and how long it is kept.

## Price

The betas are free and include every feature. Version 1.0 is planned to offer a free trial and a one-time purchase, with no subscription and no ads.

## Feedback

Email vesqen@sumirenokai.com or [open an issue](https://github.com/Sumire-no-kai/Vesqen/issues/new/choose). A device report (Settings → Privacy & data → Export device report) tells us your phone, Android version and output path, so you don't have to type them.

## 中文

Vesqen 的第二个公开测试版。Vesqen 是一款 Android 离线音乐播放器，播放你手机里的音乐，不用注册账号，还会写明每首歌从文件到耳机经过的路径。

### 从 beta.1 升级

beta.1 不能自己更新。请下载下面的 `Vesqen-1.0.0-beta.2.apk`，直接覆盖安装：它和 beta.1 用同一把密钥签名，曲库、歌单、收藏和设置都会保留。不要先卸载，卸载会删掉这些数据。从这个版本起，Vesqen 可以自己检查并安装更新。

### 这个版本有什么

- **新的界面。** 曲库、正在播放、链路、设置、播放队列、曲目信息和“关于”都重新设计，用纸张色调和衬线标题，浅色和深色都有。播放时，正在播放页占满整个屏幕；启动时会画出细调过的应用图标。
- **链路页一眼看懂。** 它按五步跟着声音走，从文件一直到输出，并写明 Vesqen 自己这一段有没有改动音频。用蓝牙时分两段显示：Vesqen 这一段，以及系统的蓝牙编码，后者是有损或未知的。
- **应用内更新。** “设置 → 更新”每天最多自动检查一次，也可以点“检查更新”。只有你同意时才下载，下载后核对 SHA-256 和签名，安装时由 Android 请你确认。
- **设备报告。** 遇到问题想让我们看看时，可以在“设置 → 隐私与数据 → 导出设备报告”里生成一份报告。内容由你挑选，先看到完整报告，再决定分享、发邮件还是上传。
- **使用统计。** 每天最多一次，不带任何 ID。在欧盟、欧洲经济区和英国，Vesqen 会先征求你的同意；其他地区默认开启，第一次打开时就可以关闭。
- **开源许可。** 应用用到的每个开源库的许可，都在设置里。
- **修复：** 未知艺术家不再显示为 `<unknown>`（#32）；链路页不再把旧数据当作当前路径显示（#33）；严格 USB 模式冷启动后不再立即弹出失败对话框（#34）；严格输出在播放中断后能正确恢复。

### 安装

- 系统要求：Android 8.0 及以上。严格 USB 输出需要 Android 14 及以上和兼容的 USB DAC。
- 下载下面的 `Vesqen-1.0.0-beta.2.apk`。SHA-256：`发布时填写`
- 应用签名证书 SHA-256：`74:3E:96:FC:B7:1D:C5:81:88:49:68:19:A0:01:A2:7C:D8:8D:90:91:62:C5:AE:92:9C:87:BF:A2:9A:B8:62:93`，可以用 `apksigner verify --print-certs` 核对。

### 已知限制

- 目前还没有任何手机和 DAC 的组合通过 bit-perfect 验证，所以还没有 `BIT-PERFECT VERIFIED` 记录。
- 严格 USB 输出还没有在真实的 DAC 上确认过。很多手机即使是 Android 14 及以上，也没有开放 Android 的 bit-perfect 通路；我们测过的 Android 14 及以上手机（vivo 和 iQOO，Android 15 和 16）都没有，严格模式在这些手机上会停止播放并说明原因。用系统输出时，USB DAC 和 USB 音箱照常可以播放。
- Android 13 及以下没有官方的 bit-perfect 混音接口，所以不能使用严格 USB 输出。
- 蓝牙不可能 bit-perfect。链路页可以说明 Vesqen 这一段没有改动音频，但手机仍会为蓝牙重新编码。
- Vesqen 不会把数据迁移到新手机，收藏、歌单和设置会留在原来的手机上。
- Vesqen 在后台被系统停止后，重新打开应用时会恢复播放队列；暂不支持直接用耳机按键恢复播放。
- 长时间播放、折叠屏、高刷新率和完整的 TalkBack 读屏体验还在测试中。

### 隐私

播放和曲库仍然从不使用网络。这个版本第一次用到网络，用在三件事上，每一项都可以关闭：使用统计、你自己选择上传的设备报告，以及检查更新。[隐私政策](https://vesqen.sumirenokai.com/zh/privacy/)写明了每一项发送什么、保留多久。

### 价格

测试版免费，可以使用全部功能。正式版计划提供免费试用和一次性买断，不做订阅，也没有广告。
