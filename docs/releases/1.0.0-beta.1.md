**English** · [中文](#中文)

The first public beta of Vesqen, an offline music player for Android. It plays the music stored on your phone, needs no account, and shows the path each track takes from the file to your headphones.

## What's in this beta

- Local library through Android's media library and folders you add: songs, albums, artists, folders, genres and playlists, favorites, and a queue that is still there next time.
- Background playback with controls in the notification and on the lock screen.
- The Chain page: the source file, the decoder, AudioTrack and the output route, each value marked as measured, derived or estimated, with the time it was observed.
- Strict USB output on Android 14 and later with a compatible USB DAC. If it can't be kept, Vesqen stops playback and tells you why.
- Output verification records. `BIT-PERFECT VERIFIED` appears only when a signed record matches the exact app build, phone and ROM, DAC and formats.
- The privacy policy in English and Chinese, under Settings → About.

## Install

- Requirements: Android 8.0 or later. Strict USB output needs Android 14 or later and a compatible USB DAC.
- Download `Vesqen-1.0.0-beta.1.apk` below. SHA-256: `5670977b4f68c648dbf46396cf06d3f188ef3993dc438e4da64b25ba79f9b396`
- Application signing certificate SHA-256: `74:3E:96:FC:B7:1D:C5:81:88:49:68:19:A0:01:A2:7C:D8:8D:90:91:62:C5:AE:92:9C:87:BF:A2:9A:B8:62:93`. Check it with `apksigner verify --print-certs`. Later versions from GitHub and Google Play use the same key and update this install in place.
- This is the first public release, so there is nothing to upgrade from.

## Known limitations

- No phone and DAC combination has been verified bit-perfect yet, so no `BIT-PERFECT VERIFIED` record exists.
- Strict USB output hasn't been confirmed with a real DAC yet. Many phones don't offer Android's bit-perfect path, even on Android 14 and later. None of the Android 14+ phones we tested (vivo and iQOO, on Android 15 and 16) offer it, so strict mode stops there and tells you why. System output still plays through USB DACs and speakers as usual.
- Android 13 and earlier don't provide the official bit-perfect mixer API, so strict USB output isn't available there.
- If Android stops Vesqen in the background, the queue comes back when you open the app again. Resuming straight from headphone buttons isn't supported yet.
- Long listening sessions, foldables, high refresh rates and complete TalkBack coverage are still being tested.
- Known interface issues, fixed in later betas: an unknown artist can show as `<unknown>` (#32), the Chain page can show older values as if they described the current path (#33), and strict USB mode can show a failure dialog right after a cold start (#34).

## Privacy

Vesqen doesn't request the Internet permission, so the app itself can't send or receive data. Your library and playlists stay on your phone. [Privacy policy](https://vesqen.sumirenokai.com/privacy/)

## Feedback

Email vesqen@sumirenokai.com or [open an issue](https://github.com/Sumire-no-kai/Vesqen/issues/new/choose). Include the app version, phone model, Android version, DAC or headphones and the file format; for output problems, add a screenshot of the Chain page. You don't need to turn on any logging.

## 中文

Vesqen 的第一个公开测试版。Vesqen 是一款 Android 离线音乐播放器，播放你手机里的音乐，不用注册账号，还会写明每首歌从文件到耳机经过的路径。

### 这个版本有什么

- 本地曲库：通过 Android 媒体库和你添加的文件夹查找音乐，可以按歌曲、专辑、艺术家、文件夹、流派和歌单浏览，支持收藏；播放队列下次打开还在。
- 后台播放，通知栏和锁屏都能直接控制。
- 链路页：显示源文件、解码器、AudioTrack 和输出路由，每个数值都标明是实测、推导还是估算，以及观测时间。
- Android 14 及以上配合兼容的 USB DAC 可以使用严格 USB 输出。条件保持不了时，Vesqen 会停止播放并说明原因。
- 输出验证记录：只有签名记录与应用版本、手机和系统、DAC、格式完全一致时，才会显示 `BIT-PERFECT VERIFIED`。
- 中英文隐私政策，在“设置 → 关于”里。

### 安装

- 系统要求：Android 8.0 及以上。严格 USB 输出需要 Android 14 及以上和兼容的 USB DAC。
- 下载下面的 `Vesqen-1.0.0-beta.1.apk`。SHA-256：`5670977b4f68c648dbf46396cf06d3f188ef3993dc438e4da64b25ba79f9b396`
- 应用签名证书 SHA-256：`74:3E:96:FC:B7:1D:C5:81:88:49:68:19:A0:01:A2:7C:D8:8D:90:91:62:C5:AE:92:9C:87:BF:A2:9A:B8:62:93`，可以用 `apksigner verify --print-certs` 核对。之后 GitHub 和 Google Play 的版本都用同一把密钥签名，可以直接覆盖更新。
- 这是第一个公开版本，没有可以升级的旧版本。

### 已知限制

- 目前还没有任何手机和 DAC 的组合通过 bit-perfect 验证，所以还没有 `BIT-PERFECT VERIFIED` 记录。
- 严格 USB 输出还没有在真实的 DAC 上确认过。很多手机即使是 Android 14 及以上，也没有开放 Android 的 bit-perfect 通路；我们测过的 Android 14 及以上手机（vivo 和 iQOO，Android 15 和 16）都没有，严格模式在这些手机上会停止播放并说明原因。用系统输出时，USB DAC 和 USB 音箱照常可以播放。
- Android 13 及以下没有官方的 bit-perfect 混音接口，所以不能使用严格 USB 输出。
- Vesqen 在后台被系统停止后，重新打开应用时会恢复播放队列；暂不支持直接用耳机按键恢复播放。
- 长时间播放、折叠屏、高刷新率和完整的 TalkBack 读屏体验还在测试中。
- 已知的界面问题会在之后的测试版修复：未知艺术家可能显示为 `<unknown>`（#32）；链路页可能把旧数据当作当前的播放路径显示（#33）；严格 USB 模式在冷启动后可能立即弹出失败对话框（#34）。
