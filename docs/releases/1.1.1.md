**English** · [中文](#中文)

Vesqen 1.1.1 adds back the folders you added after Vesqen rebuilds damaged library data, and fixes problems found in a review of the whole app after 1.1.0.

## Upgrading

Open Settings → Updates and tap Check for updates, or download `Vesqen-1.1.1.apk` below and install it over 1.1.0, 1.0.1, 1.0.0 or any beta from beta.2 on. Your library, playlists, favorites and settings stay. Vesqen 1.1.1 needs Android 9.0 or later.

## What's improved

- **Rebuilt library data.** If Vesqen has to rebuild damaged library data, folders added with Add music folder are added back and scanned again. They no longer have to be added again.
- **Folders on different storage.** Folders with the same path on the phone and on an SD card, or two added folders with the same name, are no longer shown as one folder, and Play all no longer mixes their songs. When two folders would look the same in the folder list, each row shows which storage it is on.
- **Seeking.** If the song changes while you drag the progress bar, for example because it ends or a headphone button skips it, the new song no longer jumps to the position meant for the old one.
- **Pausing a scan.** Pausing the scan of a large added folder now takes effect at once.
- **Artwork.** Artwork that some MP3 files store with a UTF-16 description now shows.
- **Bluetooth.** Chain and Now show the codec of the Bluetooth device that is playing, not that of another connected device.
- **Keyboard and accessibility.** The A–Z index beside the Library opens the letter list with a keyboard or Switch Access.
- **Remote switch.** Usage statistics or device report uploads that we have stopped for good stay off for the rest of this version, even when the other one is still active.

## Install

- Requirements: Android 9.0 or later. Strict USB output needs Android 14 or later and a compatible USB DAC.
- Download `Vesqen-1.1.1.apk` below. SHA-256: `(发布时填写)`
- Application signing certificate SHA-256: `74:3E:96:FC:B7:1D:C5:81:88:49:68:19:A0:01:A2:7C:D8:8D:90:91:62:C5:AE:92:9C:87:BF:A2:9A:B8:62:93`. Check it with `apksigner verify --print-certs`.
- The [Support page](https://vesqen.sumirenokai.com/support/#install-title) on the Vesqen website explains step by step how to install the APK.

## Known limitations

- No phone and DAC combination has been verified bit-perfect yet, so no `BIT-PERFECT VERIFIED` record exists.
- Strict USB output hasn't been confirmed with a real DAC yet. Many phones don't offer Android's bit-perfect path, even on Android 14 and later. None of the Android 14+ phones we tested (vivo and iQOO, on Android 15 and 16) offer it, so strict mode stops there and tells you why. System output still plays through USB DACs and speakers as usual.
- Android 13 and earlier don't provide the official bit-perfect mixer API, so strict USB output isn't available there.
- Even on phones that do offer the bit-perfect path, strict USB output currently stops for most files: Vesqen hands Android floating-point audio, and USB DACs' bit-perfect formats are integer. It stops and says why instead of playing something that isn't bit-perfect. This is being fixed together with Vesqen's own USB output, planned for 2.0.
- In strict USB mode, there is a short gap between tracks, even on gapless albums.
- Same-name `.lrc` files are read only in folders added with Add music folder, not for songs that Vesqen finds through Android's media library.
- On Android 9, folders with the same path on the phone and on an SD card are still shown as one folder.
- Bluetooth is never bit-perfect. The Chain page can say that Vesqen's part left the audio unchanged; the phone still re-encodes it for Bluetooth.
- After Android stops Vesqen in the background, the Play button in the notification shade and on the lock screen can't restart it on Android 13 and later. Headphone buttons may not work either: the vivo (Android 15) and Honor (Android 9) phones we tested pass them only to music apps on a list built into the phone's system, and Vesqen isn't on it. Open Vesqen to continue where you left off.
- On vivo phones, Vesqen's playback controls show on the lock screen only after you turn on Lock screen notifications for Vesqen in the phone's notification settings.
- Some phone makers' systems pause music on their own. For example, on our vivo test phone, the system paused Vesqen about three minutes after the media volume was turned all the way down with the volume keys.
- Vesqen doesn't move its data to a new phone. Favorites, playlists and settings stay on the old phone.
- Vesqen hasn't been tested on foldables, and its smoothness at high refresh rates hasn't been measured. TalkBack was checked on an Android 16 emulator, not yet on a phone.

The current list, with what is being fixed before 2.0 and what 2.0 is planned to bring, is in [issue #163](https://github.com/Sumire-no-kai/Vesqen/issues/163) and on the [website](https://vesqen.sumirenokai.com/status/).

## 中文

Vesqen 1.1.1 在重建损坏的曲库数据后会自动加回你添加的文件夹，并修正了 1.1.0 发布后全面审查中发现的问题。

### 升级

打开"设置 → 更新"，点按"检查更新"；或下载下面的 `Vesqen-1.1.1.apk`，直接覆盖安装 1.1.0、1.0.1、1.0.0 或 beta.2 及以后的测试版。曲库、歌单、收藏和设置均会保留。Vesqen 1.1.1 需要 Android 9.0 及以上版本。

### 改进与修正

- **曲库数据重建。** Vesqen 需要重建损坏的曲库数据时，通过"添加音乐文件夹"加入的文件夹会自动重新添加并扫描，无需再手动添加。
- **不同存储上的文件夹。** 手机和 SD 卡上路径相同的文件夹，以及两个同名的添加文件夹，不再合并显示为一个文件夹，"全部播放"也不再混合其中的歌曲。文件夹列表中两行看起来相同时，每行会标出所在的存储。
- **拖动进度。** 拖动进度条时如果切换了歌曲（例如歌曲播放完毕或用耳机按键切歌），新歌曲不再跳到原本为上一首设定的位置。
- **暂停扫描。** 暂停扫描较大的添加文件夹时，会立即生效。
- **封面。** 部分 MP3 文件中带 UTF-16 描述的封面现在可以正常显示。
- **蓝牙。** 链路页和"正在播放"页显示的是正在播放的蓝牙设备的编码，不再显示其他已连接设备的编码。
- **键盘与无障碍。** 曲库旁的 A–Z 索引可以用键盘或"开关控制"打开字母列表。
- **远程开关。** 我们已永久停用的使用统计或设备报告上传，在本版本内会一直保持关闭，不受另一项服务状态的影响。

### 安装

- 系统要求：Android 9.0 及以上版本。严格 USB 输出需要 Android 14 及以上版本和兼容的 USB DAC。
- 下载下面的 `Vesqen-1.1.1.apk`。SHA-256：`(发布时填写)`
- 应用签名证书 SHA-256：`74:3E:96:FC:B7:1D:C5:81:88:49:68:19:A0:01:A2:7C:D8:8D:90:91:62:C5:AE:92:9C:87:BF:A2:9A:B8:62:93`，可使用 `apksigner verify --print-certs` 核对。
- Vesqen 官网的[支持页](https://vesqen.sumirenokai.com/zh/support/#install-title)提供安装 APK 的分步说明。

### 已知限制

- 目前尚无任何手机与 DAC 的组合通过 bit-perfect 验证，因此还没有 `BIT-PERFECT VERIFIED` 记录。
- 严格 USB 输出尚未在真实的 DAC 上确认。很多手机即使是 Android 14 及以上版本，也没有开放 Android 的 bit-perfect 通路；我们测试过的 Android 14 及以上手机（vivo 和 iQOO，Android 15 和 16）均未开放，严格模式在这些手机上会停止播放并说明原因。使用系统输出时，USB DAC 和 USB 音箱可照常播放。
- Android 13 及以下版本没有官方的 bit-perfect 混音接口，因此无法使用严格 USB 输出。
- 即使手机开放了 bit-perfect 通路，严格 USB 输出目前遇到大多数文件仍会停止：Vesqen 交给 Android 的是浮点音频，而 USB DAC 的 bit-perfect 格式是整数。Vesqen 会停止播放并说明原因，不会播放实际并非 bit-perfect 的结果。这一问题将与计划在 2.0 推出的 Vesqen 自研 USB 输出一并解决。
- 严格 USB 模式下切换歌曲时会有短暂的间隔，无缝专辑也是如此。
- 同名 `.lrc` 文件仅在通过"添加音乐文件夹"加入的文件夹中读取；Vesqen 通过系统媒体库找到的歌曲不读取同名文件。
- 在 Android 9 上，手机和 SD 卡上路径相同的文件夹仍会合并显示为一个文件夹。
- 蓝牙无法实现 bit-perfect。链路页可以说明 Vesqen 这一段未改动音频，但手机仍会为蓝牙重新编码。
- Vesqen 在后台被系统停止后，在 Android 13 及以上版本中，通知栏和锁屏上的播放按钮无法使其恢复。耳机按键也未必有效：我们测试过的 vivo（Android 15）和 Honor（Android 9）手机只把耳机按键交给系统内置名单中的音乐应用，Vesqen 不在名单中。打开 Vesqen 即可从原来的位置继续播放。
- 在 vivo 手机上，需要在系统的通知设置中为 Vesqen 打开"锁屏通知"，锁屏上才会显示 Vesqen 的播放控件。
- 部分手机厂商的系统会自行暂停音乐。例如在我们的 vivo 测试机上，用音量键把媒体音量调到 0 约三分钟后，系统暂停了 Vesqen。
- Vesqen 不会把数据迁移到新手机，收藏、歌单和设置会留在原来的手机上。
- 尚未在折叠屏上测试，高刷新率下的流畅度也尚未测量。TalkBack 已在 Android 16 模拟器上检查，尚未在真机上测试。

最新的列表，以及 2.0 之前要修复的问题和 2.0 的计划，见 [issue #163](https://github.com/Sumire-no-kai/Vesqen/issues/163) 和[官网](https://vesqen.sumirenokai.com/zh/status/)。
