# Vesqen 隱私政策

- 生效日期：2026 年 9 月 26 日
- 最後更新：2026 年 11 月 1 日

本政策說明 Vesqen Android 應用程式處理的資訊、資訊的儲存位置、經由網路傳送的內容，以及您聯絡我們或參加測試時，我們會收到的資訊。本政策適用於我們透過 Google Play、GitHub Releases 及其他方式發布的所有 Vesqen 版本，也適用於 Vesqen 官方網站。

## 摘要

- Vesqen 用於播放裝置上的音樂，無須建立帳號。應用程式不含廣告、追蹤功能、第三方統計分析或當機回報元件。
- 播放與曲庫功能均在離線狀態下運作。曲庫、收藏、播放清單及播放記錄儲存在您裝置上的應用程式私人儲存空間，不會傳送給我們。
- 自 1.0.0-beta.2 起，Vesqen 會透過網路傳送每日最多一次的使用統計，以及您選擇上傳的裝置報告。GitHub 版另提供更新檢查。各項功能均可關閉，詳細說明見下文。
- 使用統計不含安裝 ID、裝置 ID、位置資訊、音樂內容或聆聽內容。在歐盟、歐洲經濟區、英國、中國大陸及韓國，Vesqen 會在取得您的同意後才傳送統計；其他地區預設開啟，您可在首次啟動的說明頁面關閉。
- 我們也會收到您主動提供的資訊，例如客服電子郵件的內容，以及參加測試時提供的電子郵件地址。
- Vesqen 官方網站使用無須 Cookie 的 Cloudflare Web Analytics 統計瀏覽量，並在取得您的同意後，以 Cookie 記住語言選擇。網站不含廣告或追蹤 Cookie。

## 應用程式在您裝置上處理的資訊

下列資訊均在您的裝置上處理。只有您主動將資訊納入裝置報告時，相關內容才會傳送給我們或第三方。

- **音樂曲庫。** Vesqen 會在您授權存取的音訊檔案與資料夾中，讀取檔名、資料夾名稱、檔案大小、修改時間、標籤（例如曲名、演出者、專輯、專輯演出者、曲風、年份、曲目編號及光碟編號）、內嵌封面，以及音訊格式資訊（例如編碼、取樣率、位元深度、聲道數及位元率）。
- **應用程式使用記錄。** 包括收藏及其順序、播放清單（名稱、曲目、順序、建立及修改時間）、各曲目的播放次數與最近播放時間、目前的播放佇列與播放位置，以及您的設定。
- **播放鏈路。** 為顯示「鏈路」頁面及執行嚴格 USB 輸出，Vesqen 會讀取 Android 提供的音訊路由資訊，包括目前輸出裝置的名稱與類型（含已連接的藍牙音訊裝置），以及 USB 音訊裝置的廠商 ID、產品 ID、名稱、USB 描述元版本與支援格式。Vesqen 不會要求直接存取 USB 裝置。在 Android 13 以上版本，若您授予「附近的裝置」權限，Vesqen 也會接收 Android 回報的耳機或喇叭藍牙編碼（例如 96 kHz 的 LDAC），並顯示於「鏈路」頁面。這些資訊僅留存在手機上，裝置中斷連線後即清除。
- **輸出驗證記錄。** 匯入驗證記錄檔案後，Vesqen 會將檔案儲存於私人儲存空間。為判定是否顯示 `BIT-PERFECT VERIFIED`，應用程式會將記錄與目前組態比對，包括已安裝應用程式的版本與安裝套件雜湊值、手機製造商、型號、Android 版本、在裝置上計算的系統版本指紋（Build fingerprint）雜湊值、已連接的 USB 音訊裝置，以及目前播放的音訊格式。
- **最近的錯誤。** Vesqen 會保留過去 7 天內最多 100 筆播放錯誤、嚴格 USB 輸出停止原因及 Android 提供的應用程式結束原因。對於播放失敗的曲目，也會記錄其格式與檔名，供您決定是否納入裝置報告。
- **當機記錄。** Vesqen 因未處理的錯誤而當機時，會儲存錯誤類型、導致錯誤的程式碼位置（類別名稱、方法名稱及行號）、相關底層錯誤，以及應用程式版本與發生時間。錯誤訊息本文可能包含檔案路徑或曲名，因此不予記錄。最近 3 次當機記錄最多保留 7 天，並於您上傳報告或選擇「不傳送」後刪除。透過分享或電子郵件傳送報告後，應用程式無法確認傳送是否完成，因此仍會保留記錄至期限屆滿。
- **所在地區。** 為判定傳送使用統計前是否須取得同意，Vesqen 會讀取手機語言設定的地區、SIM 卡與行動網路的國家代碼，以及時區設定對應的國家。時區資訊僅用於決定是否先徵求同意，不會據此預設開啟統計。此程序無須權限，判定結果僅在裝置上使用，不予儲存或傳送。

Vesqen 不會修改或刪除您的音樂檔案。

## 權限

| 權限 | 用途 |
| --- | --- |
| 讀取音訊檔案（Android 13 以上為 `READ_MEDIA_AUDIO`；Android 12L 以下為 `READ_EXTERNAL_STORAGE`） | 尋找並播放裝置上的音樂。 |
| 在系統選取器中授予的資料夾存取權 | 讀取所選資料夾中的音樂。存取權限為唯讀，您可隨時移除資料夾的登錄。 |
| 通知（`POST_NOTIFICATIONS`） | 播放音樂時顯示播放控制項。 |
| 媒體播放前景服務與喚醒鎖定 | 螢幕關閉或應用程式在背景執行時，維持音樂播放。 |
| 修改音訊設定（`MODIFY_AUDIO_SETTINGS`） | 開啟嚴格 USB 輸出時，向 Android 要求使用 bit-perfect USB 輸出模式。 |
| 附近的裝置（`BLUETOOTH_CONNECT`，Android 13 以上） | 選用權限，僅在您選擇顯示藍牙編碼時要求授權，用於接收 Android 回報的編碼。應用程式不會搜尋、配對或連接藍牙裝置。 |
| 網際網路存取（`INTERNET`） | 用於下文所述的使用統計、裝置報告上傳及 GitHub 版更新檢查。播放與曲庫功能不使用網路。 |
| 網路狀態（`ACCESS_NETWORK_STATE`） | 傳送使用統計前，確認是否有可用的網路連線。Vesqen 使用的 Google Media3 播放程式庫也宣告了此權限。 |
| 安裝應用程式（`REQUEST_INSTALL_PACKAGES`） | 僅用於 GitHub 版，安裝您在 Vesqen 中下載的更新。每次安裝均由 Android 要求您確認。 |
| USB 主機（選用硬體功能） | 識別 USB 音訊裝置。不支援 USB 主機的手機也可安裝 Vesqen。 |

讀取音樂為必要權限。拒絕通知、資料夾存取或「附近的裝置」權限後，Vesqen 仍可播放已取得讀取權限的音樂。應用程式不會要求位置、聯絡人、電話、相機或麥克風權限。

## 資訊傳送至應用程式外部的情況

- **Android 媒體控制。** 播放時，Vesqen 會將曲名、演出者、專輯、封面及播放位置提供給 Android，以顯示通知與鎖定畫面的播放控制項。Android 可能將資訊提供給您已連接或授權的車用系統、手錶或語音助理等。僅 Android 系統元件，以及您已授予通知讀取或媒體控制權限的應用程式（例如智慧手錶應用程式），可連接 Vesqen 的播放工作階段。
- **更換手機。** Vesqen 不會將應用程式資料移轉至新手機。曲庫、收藏、播放清單、播放次數與最近播放時間、播放佇列、設定及輸出驗證記錄均保留在原手機。使用新手機時，您須重新授予音訊檔案讀取權限，或再次加入音樂資料夾。Vesqen 已停用 Android 雲端備份，因此資料不會備份至 Google 雲端硬碟；應用程式也要求 Android 在裝置間移轉時排除這些資料。部分手機製造商的移轉工具可能未遵循此要求，仍會複製應用程式資料。
- **支持開發。** GitHub 版的「關於」頁面提供「支持開發」連結，並會不定期顯示支持開發的提示。這兩項操作僅透過瀏覽器開啟 Buy Me a Coffee 頁面，Vesqen 本身不會傳送任何資訊。為決定提示時機，應用程式會在裝置上記錄顯示次數、上次顯示時間，以及您是否選擇不再顯示。Google Play 版未提供這兩項功能。
- **網路功能。** 應用程式僅在使用統計、上傳裝置報告及檢查更新（限 GitHub 版）時使用網路，包括各項功能所需的狀態檔案讀取與下載。詳細內容分別列於以下三節。

## 使用統計

- **傳送資訊。** 開啟 Vesqen 時，每日最多傳送一次下列資訊：應用程式版本與發布管道；Android 版本、手機製造商、型號及系統版本名稱；Android 可判定時，已連接 USB 音訊裝置對 bit-perfect 模式的支援情形；過去 7 天內是否曾連接 USB 音訊裝置；以及是否為當日、當週及當月的首次訊息。
- **不含資訊。** 統計不含安裝 ID、裝置 ID、帳號、位置、國家、音樂、檔名或聆聽內容。
- **裝置上保留的資訊。** 應用程式會記錄上次傳送統計的時間，以及最近辨識到 USB 音訊裝置的時間，用於限制每日傳送次數及填寫上述統計項目。
- **接收者。** 統計傳送至我們設於 Cloudflare 的統計服務。服務僅累加每日總數，不儲存原始訊息或 IP 位址。Cloudflare 為傳遞請求及保護服務而處理 IP 位址，並保留後述的抽樣請求記錄。回應可能包含最新版本資訊，供 GitHub 版檢查更新。
- **您的選擇。** 在歐盟、歐洲經濟區、英國、中國大陸、韓國，以及無法確定國家時，Vesqen 會先徵求同意，且不會預選任何選項；取得同意前不會傳送統計。其他地區預設開啟，首次啟動的說明頁面會列明統計內容並提供開關，離開該頁面前不會傳送。您可隨時在「設定 → 隱私與資料 → 使用統計」關閉，關閉後立即停止傳送。已傳送的統計已計入無法與個人關聯的每日總數，因此無法個別刪除。
- **服務狀態檢查。** 傳送統計或上傳報告前，Vesqen 會讀取官方網站的服務狀態檔案，確認服務是否暫停，每 10 分鐘最多讀取一次。關閉統計後，僅在上傳報告時讀取。除 IP 位址等網路通訊所需資訊外，請求不含與您有關的內容。

## 裝置報告

- **產生報告。** 您可在「設定 → 隱私與資料 → 匯出裝置報告」產生協助排查問題的報告。報告固定包含應用程式版本與建置類型、手機製造商、型號、Android 版本、系統版本名稱及產生時間。您可另行選取音訊輸出能力（包括 USB 音訊裝置的廠商 ID、產品 ID 及支援格式）、鏈路頁面的數值（例如格式、解碼器、緩衝區、電池、處理器讀值及 Android 回報的藍牙編碼）、前述最近錯誤與當機記錄、播放失敗曲目的格式，並另外決定是否包含檔名。藍牙裝置名稱、輸出路由名稱、解碼器名稱與處理器型號均會移除。報告傳送至應用程式外部前，您可預覽完整內容。
- **當機後的處理。** 若 Vesqen 上次當機或未回應，應用程式會在下次開啟時詢問一次是否傳送報告。選擇「查看並傳送」會開啟「匯出裝置報告」，並預先選取當機記錄與最近的錯誤。您可先預覽完整報告，再選擇上傳、分享或透過電子郵件傳送。選擇「不傳送」會刪除已儲存的當機記錄。報告僅在您確認傳送後送出。
- **傳送報告。** 您可將報告分享至所選應用程式、透過電子郵件寄給我們，或直接上傳。分享與電子郵件均由您所選的應用程式處理。Vesqen 會在快取中保留最近的報告檔案供分享使用，並於下次分享時刪除超過一天的檔案。
- **上傳報告。** 報告會上傳至我們設於 Cloudflare 的服務。服務儲存報告、隨機產生的回執編號及接收時間，不儲存 IP 位址。除非您向我們提供回執編號，否則無法將報告與您關聯。上傳的報告保留 7 天後刪除。如需提前刪除，請透過電子郵件提供回執編號。

## 檢查更新

- **檢查。** GitHub 版可在開啟應用程式時自動檢查新版本，每日最多一次；您也可點選「檢查更新」。檢查時會讀取由 Cloudflare 託管的官方網站 vesqen.sumirenokai.com 上的版本檔案。開啟使用統計時，版本資訊可能隨統計回應一併傳回，此時不會另行提出請求。請求不含識別碼，僅包含 IP 位址等網路通訊所需資訊。您可在「設定 → 更新 → 自動檢查更新」關閉自動檢查。
- **下載。** Vesqen 僅在您點選「下載」後下載更新。檔案由 GitHub 提供，適用其隱私聲明。安裝前，Vesqen 會核對檔案的 SHA-256 與簽署憑證，Android 也會要求您確認。未通過核對的檔案將予以刪除；通過核對的檔案則儲存在應用程式私人儲存空間，直到下次開啟應用程式，以便取消安裝後重試時無須再次下載。
- **其他來源。** Google Play 版由 Google Play 提供更新，不另行檢查。若由其他應用程式（例如 F-Droid 用戶端）管理 GitHub 版的更新，自動檢查預設關閉。

## 我們收到的資訊

- **聯絡電子郵件。** 您聯絡我們時，我們會收到電子郵件地址、郵件內容及附件（例如裝置報告），僅用於回覆。寄至 sumirenokai.com 電子郵件信箱的郵件，會經由 Cloudflare 郵件轉寄服務，儲存在我們的 Microsoft Outlook 電子郵件信箱。
- **統計與報告。** 對於使用統計，我們僅能查閱每日彙總；上傳的裝置報告則可於 7 天保留期限內查閱。
- **封閉測試。** 參加 Google Play 測試時，您的 Google 帳號電子郵件地址會加入 Google Play 管理中心的該次測試名單，供 Google 授予測試版存取權。我們也可查閱您透過 Google Play 提供的意見，相關資訊僅用於辦理測試。
- **應用程式內購。** Vesqen 目前未提供應用程式內購。若未來版本加入此功能，我們會在該版本發布前更新本政策。
