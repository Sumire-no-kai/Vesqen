# Vesqen 隱私政策

- 生效日期：2026 年 9 月 26 日
- 最後更新：2026 年 11 月 1 日

本政策說明 Vesqen Android 應用程式會處理哪些資訊、相關資訊的存儲位置、應用程式通過網路發送的資訊，以及您聯繫我們或參加測試時我們接收的資訊。本政策適用於我們分發的所有 Vesqen 版本，包括 Google Play 和 GitHub Releases，也適用於 Vesqen 官網。

## 摘要

- Vesqen 播放您設備上的音樂。本應用程式不設賬號，不含廣告或追蹤功能，也不包含任何第三方統計分析或崩潰報告組件。
- 播放和曲庫從不使用網路。您的曲庫、收藏、播放清單和播放記錄均保存在您設備上的應用程式私有存儲中，不會發送給我們。
- 從 1.0.0-beta.2 起，Vesqen 通過網路提供以下功能：每天最多一次的使用統計，以及您選擇上傳的設備報告。GitHub 版還會檢查更新。下文分別說明，每一項都可以關閉。
- 使用統計不包含任何安裝 ID 或設備 ID，也從不包含您的位置、您的音樂或您的收聽內容。在歐盟、歐洲經濟區、英國、中國大陸和韓國，Vesqen 會先徵求您的同意再發送；在其他地區預設開啓，可在首次啓動時的說明頁面關閉。
- 我們還會收到您主動向我們提供的內容，例如支持郵件；參加測試時，還會收到您的郵箱地址。
- Vesqen 官網沒有廣告，也沒有追蹤 Cookie。官網使用無需 Cookie 的 Cloudflare Web Analytics 統計訪問量；僅在您同意後，才使用 Cookie 記憶您的語言選擇。

## 應用程式在您設備上處理的資訊

以下資訊在您的設備上處理。除非您主動將相關資訊納入設備報告，否則不會向我們或任何第三方發送。

- **您的曲庫。** 在您允許訪問的音頻檔案和資料夾中，Vesqen 會讀取檔案名、所在資料夾名、檔案大小、修改時間、標籤（例如標題、藝術家、專輯、專輯藝術家、流派、年份、音軌號和碟號）、內嵌封面，以及音頻格式資訊（例如編碼、採樣率、位深、聲道數和碼率）。
- **應用程式內使用記錄。** 收藏及其順序、播放清單（名稱、曲目、順序以及創建和修改時間）、每首歌的播放次數和最近播放時間、當前播放隊列和播放位置，以及您的設置。
- **您的播放鏈路。** 為顯示 Chain 頁面並執行嚴格 USB 輸出，Vesqen 會讀取 Android 提供的音頻路由資訊：當前輸出設備的名稱和類型（包括已連接的藍牙音頻設備），以及 USB 音頻設備的廠商 ID、產品 ID、名稱、USB 描述符版本和支持的音頻格式。Vesqen 不會申請直接訪問 USB 設備。在 Android 13 及以上，如果您允許“附近的設備”權限，Vesqen 還會接收 Android 報告的已連接耳機或音箱的藍牙編碼（例如 96 kHz 的 LDAC），並在 Chain 頁面顯示。相關資訊僅保留在您的手機上，並在設備斷開後清除。
- **輸出驗證記錄。** 如果您導入一份驗證記錄檔案，Vesqen 會將其保存在私有存儲中。為判斷是否顯示 `BIT-PERFECT VERIFIED`，Vesqen 會將記錄與您當前的配置進行比對：已安裝應用程式的版本和安裝包哈希值、手機的廠商、型號和 Android 版本、在本機計算出的系統版本指紋（Build fingerprint）哈希值、已連接的 USB 音頻設備，以及正在播放的音頻格式。
- **最近的錯誤。** Vesqen 會記錄最近的播放錯誤、嚴格 USB 輸出停止的原因，以及 Android 提供的應用程式關閉原因，最多保留最近 7 天內的 100 條。對於播放失敗的歌曲，會記錄該歌曲的格式和檔案名。該記錄用於供您選擇是否納入設備報告。
- **崩潰記錄。** 如果 Vesqen 因未處理的錯誤而崩潰，應用程式會記錄錯誤類型和導致錯誤的代碼位置（類名、方法名和行號），包括引發該錯誤的底層錯誤，以及應用程式版本和出錯時間。錯誤附帶的說明文字可能含有檔案路徑或歌名，Vesqen 從不記錄。它最多保留最近 3 次崩潰，最長 7 天；您上傳報告之後或選擇“不用了”後刪除。分享或通過郵件發送後，Vesqen 無法確認最終是否發送成功，因此會保留至 7 天期限屆滿。
- **您所在的地區。** 為了判斷發送使用統計前是否需要先徵求同意，Vesqen 會讀取手機語言設置中的地區、SIM 卡和移動網路的國家代碼，以及時區設置對應的國家。時區只會讓 Vesqen 先徵求同意，不會因此預設開啓統計。此過程無需任何權限，判斷結果只在設備上使用，不保存也不發送。

Vesqen 從不修改或刪除您的音樂檔案。

## 權限

| 權限 | 用途 |
| --- | --- |
| 讀取音頻檔案（Android 13 及以上為 `READ_MEDIA_AUDIO`；Android 12L 及以下為 `READ_EXTERNAL_STORAGE`） | 查找並播放您設備上的音樂。 |
| 您在系統選擇器中授權的資料夾訪問 | 從您選擇的資料夾中讀取音樂。該訪問為只讀，您可以隨時移除資料夾。 |
| 通知（`POST_NOTIFICATIONS`） | 在播放時顯示播放控制。 |
| 媒體播放前台服務和喚醒鎖 | 在熄屏或 Vesqen 處於後台時繼續播放。 |
| 修改音頻設置（`MODIFY_AUDIO_SETTINGS`） | 在您開啓嚴格 USB 輸出時，請求 Android 的 bit-perfect USB 輸出模式。 |
| 附近的設備（`BLUETOOTH_CONNECT`，Android 13 及以上） | 可選，只在您選擇顯示藍牙編碼時才申請。只用於接收 Android 報告的編碼。Vesqen 不會搜索、配對或連接藍牙設備。 |
| 網路訪問（`INTERNET`） | 用於下文所述的使用統計、上傳設備報告，以及 GitHub 版的檢查更新。播放和曲庫從不使用網路。 |
| 網路狀態（`ACCESS_NETWORK_STATE`） | 發送使用統計前，確認當前有可用的網路連接。Vesqen 使用的 Google Media3 播放庫也聲明瞭這項權限。 |
| 安裝應用程式（`REQUEST_INSTALL_PACKAGES`） | 僅 GitHub 版有，用於安裝您在 Vesqen 中下載的更新。每次安裝均由 Android 請求您確認。 |
| USB 主機（可選硬體功能） | 識別 USB 音頻設備。不支持 USB 主機的手機仍然可以安裝 Vesqen。 |

只有讀取音樂是必需的。即使您拒絕通知、資料夾訪問或“附近的設備”權限，Vesqen 仍然可以播放可讀取的音樂。Vesqen 不申請位置、通訊錄、電話、相機或麥克風權限。

## 資訊向應用程式外部提供的情形

- **Android 媒體控件。** 播放時，Vesqen 會將當前曲目的標題、藝術家、專輯、封面和播放進度提供給 Android，用於通知欄和鎖定畫面的播放控制。Android 可能將這些資訊提供給您連接或授權的設備和服務，例如藍牙車機、手錶或語音助手。只有 Android 系統組件，以及您授權過讀取通知或控制媒體播放的應用程式（例如手錶的配套應用程式），才能連接 Vesqen 的播放會話；手機上的其他應用程式無法連接。
- **更換手機。** Vesqen 不會將應用程式資料遷移至新手機。您的曲庫、收藏、播放清單、播放次數和最近播放時間、播放隊列、設置和輸出驗證記錄都只保存在原手機上；在新手機上，您需要重新允許 Vesqen 讀取音頻檔案，或重新添加音樂資料夾。Vesqen 關閉了 Android 雲備份，因此這些資料不會備份到 Google 雲端硬盤；它也要求 Android 在設備間遷移時不複製這些資料。個別手機廠商的換機工具可能不遵守這項要求，仍可能將應用程式資料複製至新手機。
- **支持開發。** GitHub 版在“關於”頁面提供“支持開發”鏈接，也會偶爾詢問您是否願意支持 Vesqen。兩者均僅在瀏覽器中打開我們的 Buy Me a Coffee 頁面，Vesqen 本身不發送任何內容。為確定提示時機，應用程式在您的設備上記錄提示次數、上次詢問的時間，以及您是否選擇了不再提示。Google Play 版均不包含上述功能。
- **網路功能。** 應用程式只在使用統計、上傳設備報告和檢查更新（僅 GitHub 版）時使用網路，包括它們各自需要的狀態檔案和下載。接下來三節分別說明。

## 使用統計

- **發送的資訊。** 每天最多一次，在您打開 Vesqen 時發送一條消息，內容只有：應用程式版本和分發渠道；Android 版本、手機廠商、型號和系統版本名稱；在 Android 能判斷時，已連接的 USB 音頻設備是否支持 Android 的 bit-perfect 模式；最近 7 天里是否連接過 USB 音頻設備；以及這是否為當天、本周和本月的首次消息。
- **不發送的資訊。** 不帶安裝 ID 或設備 ID，不涉及賬號，不包含位置或國家，也不包含您的音樂、檔案名或您的收聽內容。
- **設備上保存的資訊。** Vesqen 會記住上次發送統計的時間，以及上次檢測到 USB 音頻設備的時間。上述時間用於限制每天最多發送一次，並生成前述統計字段。
- **接收方。** 消息發送至我們部署在 Cloudflare 上的統計服務。服務將消息計入每日匯總，不保存消息本身，也不保存 IP 地址。Cloudflare 作為我們的服務商，會為傳送請求和保護服務處理您的 IP 地址，並保留下文“Cloudflare 的請求記錄”中說明的記錄。服務響應中可能附帶最新的版本資訊，GitHub 版使用該資訊檢查更新。
- **您的選擇。** 在歐盟、歐洲經濟區、英國、中國大陸和韓國，以及 Vesqen 無法確定國家時，它會先徵求您的同意，兩個選項都不預先選中；未經您同意不發送任何統計。在其他地區預設開啓：第一次打開時的說明頁會解釋統計內容並提供開關，離開該頁面之前不會發送任何內容。您可以隨時在"設置 → 隱私與資料 → 使用統計"中關閉，關閉後立即停止統計發送。已經發送的統計已計入與您無關聯的每日總數，無法單獨刪除。
- **服務可用性檢查。** 在發送統計或上傳報告之前，Vesqen 會讀取官網上的服務狀態檔案，確認該服務是否已暫停，最多每 10 分鐘讀取一次。關閉統計後，只有在您上傳報告時才會讀取。該請求除網路通信通常包含的資訊（例如您的 IP 地址），不包含任何關於您的內容。

## 設備報告

- **生成報告。** 在"設置 → 隱私與資料 → 導出設備報告"中，您可以生成用於協助排查問題的報告。報告必定包含應用程式版本和構建類型、手機廠商、型號、Android 版本、系統版本名稱以及生成時間。您可以選擇是否加入：音頻輸出能力（包括 USB 音頻設備的廠商 ID、產品 ID 和支持的格式）；鏈路頁上的數值（例如格式、解碼器、緩衝、電池和處理器讀數，以及 Android 報告的藍牙編碼）；上文所述的最近錯誤；上文所述的崩潰記錄；播放失敗的歌曲的格式；以及單獨選擇是否加入它們的檔案名。藍牙設備名稱、輸出路由名稱、解碼器名稱和處理器型號會被移除。報告離開應用程式之前，您可以查看完整內容。
- **崩潰之後。** 如果 Vesqen 上次崩潰或無響應，下次打開時會詢問一次是否發送報告。選擇“查看併發送”會打開“導出設備報告”，並預先選中崩潰記錄和最近的錯誤；您可在該頁面查看完整報告，再選擇上傳、分享或通過郵件發送。選擇“不用了”會刪除保存的崩潰記錄。只有您選擇發送時，報告才會發出。
- **發送報告。** 您可以把報告分享給您選擇的應用程式、通過郵件發給我們，或者上傳。分享和郵件通過您選擇的應用程式發送。Vesqen 會在快取中保留最近的報告檔案以便分享，並在您下次分享時刪除超過一天的檔案。
- **上傳報告。** 上傳會把報告發到我們在 Cloudflare 上的服務。服務保存報告，同時記錄隨機回執編號與接收時間，不保存 IP 地址。除非您把回執編號發給我們，否則報告不會與您關聯。上傳的報告保留 7 天後刪除。如需提前刪除，請通過郵件向我們提供回執編號。

## 檢查更新

- **檢查。** GitHub 版 Vesqen 可以檢查新版本：在您打開應用程式時每天最多自動檢查一次，您點擊"檢查更新"時也會檢查。檢查時會從我們的官網 vesqen.sumirenokai.com 讀取一個版本檔案，官網由 Cloudflare 托管。開啓使用統計時，版本資訊也可能隨統計響應一並返回，不再單獨請求。檢查不包含任何標識，只有所有網路請求都會帶有的資訊，例如您的 IP 地址。您可以在"設置 → 更新 → 自動檢查更新"中關閉自動檢查。
- **下載。** 只有在您點擊"下載"時，Vesqen 才會下載更新。檔案來自 GitHub，該下載適用 GitHub 的隱私聲明。安裝之前，Vesqen 會核對檔案的 SHA-256 和簽名證書，Android 也會請求您確認。未通過核對的檔案會被刪除；通過核對的檔案保留在 Vesqen 的私有存儲中，直到您下次打開應用程式，以便在取消安裝後重試時無需重新下載。
- **其他來源。** Google Play 版沒有自己的更新檢查，由 Google Play 負責更新。如果由其他應用程式（例如 F-Droid 客戶端）管理 GitHub 版的更新，自動檢查預設關閉。

## 我們會收到的資訊

- **您發給我們的郵件。** 如果您聯繫我們，我們會收到您的郵箱地址和郵件內容，包括您附上的設備報告，僅用於回復您。發到 sumirenokai.com 郵箱的郵件，會經 Cloudflare 的郵件轉發，保存在我們的 Microsoft Outlook 郵箱中。
- **統計和報告。** 使用統計我們僅能查看每日匯總。我們可在 7 天保留期限內查看您上傳的設備報告。

## Vesqen 官網

Vesqen 官網（vesqen.sumirenokai.com）托管在 Cloudflare 上，沒有賬號、表單和廣告。應用程式讀取的版本檔案和狀態檔案也由官網提供。

- **提供網頁。** 為了發送網頁和檔案並防止濫用，Cloudflare 會處理每一次訪問請求，其中包括您的 IP 地址、瀏覽器資訊和所訪問頁面的地址。Cloudflare 代我們處理這些資訊，也可能按它的隱私政策，用這些網路資料保護它自己的服務。Cloudflare 會向我們展示統計資料，例如各國家或地區的請求數，以及下文“Cloudflare 的請求記錄”中說明的抽樣請求記錄。我們不會用這些資訊識別訪客。
- **選擇語言。** 打開首頁時，官網按瀏覽器的語言設置顯示英文、簡體中文、繁體中文或日語；無法確定時，再參考 Cloudflare 根據 IP 地址估計的國家或地區。每次訪問都會重新判斷，不保存任何資訊。
- **訪問統計。** 官網用 Cloudflare Web Analytics 統計訪問量。每個頁面上包含 Cloudflare 腳本，會上報頁面地址、來源頁面，以及頁面加載性能；Cloudflare 會補充國家或地區、瀏覽器和設備類型。這段腳本不使用 Cookie，也不在您的瀏覽器中存儲任何資訊。我們僅能查看匯總統計，Cloudflare 最多向我們展示六個月的資料。通過 Cloudflare 位於歐盟、歐洲經濟區和英國的資料中心訪問時，不會被統計。
- **Cookie。** 第一次訪問時，官網會詢問能否記憶您的語言選擇。官網最多設置兩個 Cookie，都不用於追蹤：

| Cookie | 用途 | 保存時間 |
| --- | --- | --- |
| `vesqen-consent` | 記錄您接受或拒絕 Cookie 的選擇，避免重復詢問。 | 6 個月 |
| `vesqen-lang` | 記憶您的語言選擇。僅在您接受後設置。 | 6 個月 |

您可以隨時在每頁底部的"Cookie 設置"中更改選擇。拒絕後，官網會刪除 `vesqen-lang`。如果 Cloudflare 需要確認訪問不是由自動程序發起的，它可能會設置自己的安全 Cookie，例如 `__cf_bm` 或 `cf_clearance`。這些 Cookie 是 Cloudflare 運行服務所必需的，不會用來追蹤您。應用程式和官網都不會跨網站或跨應用程式追蹤您，因此瀏覽器的"請勿追蹤"（Do Not Track）設置不會改變上述處理方式。
