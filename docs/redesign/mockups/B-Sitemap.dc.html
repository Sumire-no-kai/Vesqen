第二批

选渠道，确认手机能不能用。

支持

第一批
/support/ · /zh/support/

出问题时来这里。

  • 联系邮箱
  • 反馈时请附上：版本、手机、系统、DAC、文件格式、链路页截图
  • 常见问题：为什么显示 SYSTEM MIXED、严格 USB 为什么用不了、换手机后怎么恢复购买
  • 已知限制：链到 GitHub issues
