# Vesqen プライバシーポリシー

- 発効日：2026 年 9 月 26 日
- 最終更新日：2026 年 11 月 1 日

本ポリシーでは、Vesqen Android アプリが扱う情報、その保存場所、ネットワーク経由で送信する情報、お問い合わせやテスト参加時に当方が受け取る情報について説明します。Google Play、GitHub Releases など当方が配布するすべての Vesqen ビルドと、Vesqen のウェブサイトに適用されます。

## 概要

- Vesqen は端末内の音楽を再生します。アカウント、広告、トラッキングはなく、第三者の利用統計・クラッシュ報告ソフトウェアも含みません。
- 再生とライブラリはネットワークを使用しません。ライブラリ、お気に入り、プレイリスト、再生履歴は端末上のアプリ専用領域に保存され、当方には送信されません。
- 1.0.0-beta.2 以降では、1 日に最大 1 回の利用統計の送信と、利用者が選択したデバイスレポートのアップロードにネットワークを使用します。GitHub 版はアップデート確認も行います。それぞれ以下で説明しており、個別に無効にできます。
- 利用統計にインストール ID や端末 ID は含まれず、位置情報、音楽、聴いた内容も含まれません。EU、欧州経済領域、英国、中国本土、韓国では、送信前に同意を求めます。それ以外の地域では初期状態で有効ですが、最初の画面で無効にできます。
- サポートメールの内容や、テスト参加時のメールアドレスなど、利用者が送ることを選択した情報も受け取ります。
- ウェブサイトには広告 Cookie やトラッキング Cookie はありません。Cookie を使用しない Cloudflare Web Analytics で訪問数を集計し、許可を得た場合にのみ言語を記憶する Cookie を使用します。

## アプリが端末上で扱う情報

Vesqen は以下の情報を端末上で処理します。利用者自身がデバイスレポートに含めない限り、当方や第三者に送信しません。

- **音楽ライブラリ。** アクセスを許可された音声ファイルとフォルダから、ファイル名、フォルダ名、サイズ、更新日時、タグ（曲名、アーティスト、アルバム、アルバムアーティスト、ジャンル、年、トラック番号、ディスク番号など）、埋め込み画像、音声形式（コーデック、サンプルレート、ビット深度、チャンネル数、ビットレートなど）を読み取ります。
- **アプリ内の操作情報。** お気に入りとその順序、プレイリスト（名前、内容、順序、作成・変更日時）、各曲の再生回数と最終再生日時、現在のキューと再生位置、設定を扱います。
- **再生経路。** 経路画面の表示と厳格 USB 出力のため、Android が提供する出力情報を読み取ります。現在の出力機器の名前と種類（接続中の Bluetooth オーディオ機器を含む）、USB オーディオ機器のベンダー ID、製品 ID、名前、USB ディスクリプターのバージョン、対応音声形式です。Vesqen は USB 機器への直接アクセスを要求しません。Android 13 以降では、「付近のデバイス」を許可した場合、LDAC・96 kHz など、接続したヘッドホンやスピーカーについて Android が報告する Bluetooth コーデックも受け取り、経路画面に表示します。この情報は端末内に留まり、接続解除時に消去されます。
- **出力検証記録。** 検証記録ファイルを読み込むと、アプリ専用領域に保存します。`BIT-PERFECT VERIFIED` を表示するか判断するため、記録と現在の構成を比較します。比較対象は、インストール済みアプリのバージョンとパッケージハッシュ、端末メーカー・モデル・Android バージョン、端末内で計算したシステムビルドフィンガープリントのハッシュ、接続中の USB オーディオ機器、再生中の音声形式です。
- **最近のエラー。** 再生エラー、厳格 USB 出力の停止、Android が示したアプリ終了理由を、過去 7 日間・最大 100 件まで記録します。再生できなかった曲については形式とファイル名も保存します。デバイスレポートに含めるか選べるようにするための記録です。
- **クラッシュの詳細。** 処理されなかったエラーで終了した場合、エラーの種類と発生までのコード位置（クラス、メソッド、行番号）、原因となったエラー、アプリのバージョン、時刻を保存します。ファイルパスや曲名が含まれる可能性があるエラーメッセージ本文は保存しません。最大 3 件を 7 日間保持し、レポートに含めてアップロードするか「送信しない」を選択すると削除します。共有・メール送信後は、実際に送信したかアプリで判断できないため、期限まで保持します。
- **地域。** 利用統計の送信前に同意を求めるか判断するため、端末の言語設定の地域、SIM と携帯電話ネットワークの国コード、タイムゾーン設定の国を読み取ります。タイムゾーンによって同意の確認を追加することはありますが、統計を有効にすることはありません。権限は不要です。結果は端末内だけで使用し、保存も送信もしません。

Vesqen は音楽ファイルを変更・削除しません。

## 権限

| 権限 | 使用目的 |
| --- | --- |
| 音声ファイルの読み取り（Android 13 以降は `READ_MEDIA_AUDIO`、Android 12L 以前は `READ_EXTERNAL_STORAGE`） | 端末の音楽を検索・再生するため。 |
| システムのフォルダ選択画面で許可したアクセス | 選択したフォルダの音楽を読むため。読み取り専用で、フォルダの登録はいつでも解除できます。 |
| 通知（`POST_NOTIFICATIONS`） | 音楽の再生中に操作ボタンを表示するため。 |
| メディア再生のフォアグラウンドサービスとウェイクロック | 画面を消したときやバックグラウンドでも再生を続けるため。 |
| オーディオ設定の変更（`MODIFY_AUDIO_SETTINGS`） | 厳格 USB 出力を有効にしたとき、Android の bit-perfect USB 出力を要求するため。 |
| 付近のデバイス（Android 13 以降の `BLUETOOTH_CONNECT`） | 任意で、Bluetooth コーデックの表示を選んだ場合だけ求めます。Android が報告するコーデックの受信だけに使用し、Bluetooth 機器の検索、ペア設定、接続は行いません。 |
| インターネット（`INTERNET`） | 後述する利用統計、デバイスレポートのアップロード、GitHub 版のアップデート確認に使用します。再生とライブラリには不要です。 |
| ネットワーク状態（`ACCESS_NETWORK_STATE`） | 利用統計を送信する前に接続が使えるか確認するため。使用している Google Media3 ライブラリもこの権限を宣言しています。 |
| アプリのインストール（`REQUEST_INSTALL_PACKAGES`） | GitHub 版のみで、Vesqen 内でダウンロードした更新をインストールするため。毎回 Android が確認を求めます。 |
| USB ホスト（任意のハードウェア機能） | USB オーディオ機器を認識するため。USB ホスト非対応の端末にもインストールできます。 |

必須なのは音楽の読み取りだけです。通知、フォルダアクセス、付近のデバイスを拒否しても、読み取れる音楽は再生できます。位置情報、連絡先、電話、カメラ、マイクの権限は要求しません。

## 情報がアプリの外に出る場合

- **Android のメディア操作。** 再生中は曲名、アーティスト、アルバム、画像、再生位置を Android に渡し、通知とロック画面の操作に使用します。Android は、接続または許可したカーオーディオ、時計、音声アシスタントなどへ渡す場合があります。再生セッションに接続できるのは Android のシステムコンポーネントと、通知の読み取りやメディア操作を利用者が許可したアプリ（スマートウォッチ用アプリなど）だけです。それ以外のアプリは接続できません。
- **機種変更。** Vesqen は新しい端末へデータを移行しません。ライブラリ、お気に入り、プレイリスト、再生回数と最終再生日時、キュー、設定、出力検証記録は古い端末にのみ残ります。新しい端末では音声ファイルの読み取りやフォルダ追加を再度許可してください。Android のクラウドバックアップを無効にしており、Google Drive にはバックアップされません。端末間転送でもコピーしないよう Android に要求します。ただし、メーカーの移行ツールによってはこの要求を無視し、データをコピーする場合があります。
- **開発支援。** GitHub 版の「アプリについて」には「開発を支援」リンクがあり、開発支援の案内を不定期に表示します。どちらもブラウザーで Buy Me a Coffee のページを開くだけで、Vesqen 自体は何も送信しません。表示時期を決めるため、表示回数、前回の日時、今後表示しないと選択したかを端末に保存します。Google Play 版にはいずれもありません。
- **ネットワーク機能。** 通信は利用統計、デバイスレポートのアップロード、GitHub 版のアップデート確認と、それらに付随する状態ファイルの読み取り・ダウンロードだけに使用します。次の 3 節で説明します。

## 利用統計

- **送信する情報。** Vesqen を開いたとき、1 日に最大 1 回、アプリのバージョンと配布経路、Android バージョン、端末メーカー・モデル・システムビルド名、Android が確認できる場合の接続 USB オーディオ機器の bit-perfect 対応状況、過去 7 日間の USB オーディオ機器接続の有無、その日・週・月の最初の送信かどうかを送ります。
- **送信しない情報。** インストール ID、端末 ID、アカウント、位置情報、国、音楽、ファイル名、聴いた内容は送信しません。
- **端末に残る情報。** 前回の統計送信日時と最後に USB オーディオ機器を認識した日時を記憶します。1 日に最大 1 回という制限と、前述の項目を埋めるために必要です。
- **送信先。** Cloudflare 上の統計サービスに送信します。サービスは日別の合計に加算し、メッセージ自体や IP アドレスは保存しません。Cloudflare はサービス提供者として配送・保護のために IP アドレスを処理し、後述のリクエスト記録を保持します。応答には、GitHub 版がアップデート確認に使用する最新バージョン情報が含まれる場合があります。
- **利用者の選択。** EU、欧州経済領域、英国、中国本土、韓国、および国を取得できない場合は、どちらの回答も事前選択せず同意を求め、同意するまで送信しません。それ以外では初期状態で有効ですが、最初の画面で説明とスイッチを表示し、その画面を離れるまで送信しません。「設定 → プライバシーとデータ → 利用統計」でいつでも無効にでき、直ちに送信を停止します。送信済みの情報は個人と結び付かない日別の合計に含まれるため、個別には削除できません。
- **サービスの停止。** 統計送信やレポートのアップロードの直前に、最大 10 分に 1 回、ウェブサイトの小さな状態ファイルを読み、当方がサービスを停止していないか確認します。統計が無効の場合、レポートのアップロード時だけ読みます。IP アドレスなど通常のウェブ通信に含まれる情報以外は送信しません。

## デバイスレポート

- **レポートの作成。** 「設定 → プライバシーとデータ → デバイスレポートを書き出す」から、不具合調査用のレポートを作成できます。アプリのバージョンとビルド、端末メーカー・モデル・Android バージョン・システムビルド名、作成日時は必ず含まれます。追加できるのは、出力能力（USB 機器のベンダー ID、製品 ID、対応形式を含む）、経路画面の値（形式、デコーダー、バッファ、電池・プロセッサーの測定値、Android が報告する Bluetooth コーデックなど）、前述の最近のエラーとクラッシュ詳細、再生できなかった曲の形式、および別項目としてそのファイル名です。Bluetooth 機器名、出力経路名、デコーダー名、プロセッサーのモデル名は削除されます。アプリの外へ送る前に全内容を確認できます。
- **クラッシュ後。** クラッシュや応答停止の後、次に開く際に一度だけ送信するか尋ねます。「確認して送信」を選択すると、クラッシュの詳細と最近のエラーを選択した状態で「デバイスレポートを書き出す」画面が開きます。全内容を確認してから、アップロード・共有・メールを選びます。「送信しない」は保存済みのクラッシュ詳細を削除します。レポートは利用者が送信を確認した場合にのみ送信します。
- **送信方法。** レポートは、選択したアプリでの共有、電子メールでの送信、またはアップロードにより提供できます。共有とメールは選択したアプリを通じて行います。最新の共有用レポートをキャッシュに保存し、次の共有時に 1 日より古いファイルを削除します。
- **アップロード。** Cloudflare 上の当方のサービスへ送信し、ランダムな受付番号と受信時刻を付けて保存します。IP アドレスは保存しません。利用者が受付番号を送らない限り、本人とは結び付きません。7 日後に削除します。早期削除を希望する場合は受付番号を電子メールでお知らせください。

## アップデートの確認

- **確認。** GitHub 版はアプリを開いたときに 1 日に最大 1 回、および「アップデートを確認」を選択したときに新しいバージョンを確認します。Cloudflare がホストする vesqen.sumirenokai.com のバージョンファイルを読みます。統計が有効な場合は統計の応答で受け取ることもあります。識別子は送らず、IP アドレスなど通常のウェブ通信に含まれる情報だけが伝わります。「設定 → アップデート → アップデートの自動確認」で無効にできます。
- **ダウンロード。** 「ダウンロード」を選択したときだけ GitHub から取得し、GitHub のプライバシーステートメントが適用されます。インストール前に SHA-256 と署名証明書を確認し、Android が確認を求めます。確認に失敗したファイルは削除します。確認に成功したファイルは次にアプリを開くまで専用領域に残り、中止したインストールを再ダウンロードせず再試行できます。
- **他のストア。** Google Play 版は Google Play が更新するため独自のアップデート確認はありません。F-Droid クライアントなど別のアプリが GitHub 版の更新を管理する場合、アップデートの自動確認は初期状態で無効です。

## 当方が受け取る情報

- **お問い合わせメール。** メールアドレス、本文、添付されたデバイスレポートなどを受け取り、返信のためだけに使用します。sumirenokai.com 宛のメールは Cloudflare のメールルーティングで転送し、Microsoft Outlook のメールボックスに保存します。
- **統計とレポート。** 統計は日別の合計だけを閲覧します。レポートはアップロードされたものを保存期間の 7 日間閲覧できます。
- **クローズドテスト。** Google Play のテストに参加すると、Google がアクセスを許可できるよう、Google アカウントのメールアドレスを Google Play Console のテスター一覧に追加します。Google Play 経由のフィードバックも受け取ります。テスト運営だけに使用します。
- **購入。** 現在アプリ内購入はありません。将来追加する場合は、そのバージョンの公開前に本ポリシーを更新します。
- **Buy Me a Coffee での支援。** 支援すると、同サービスのポリシーに従い、名前または表示名、メールアドレス、メッセージ、金額、日付が当方に表示されます。決済は Stripe が処理し、カード番号は当方に伝わりません。初期設定では名前とメッセージは当方の Buy Me a Coffee ページにも表示されますが、同サービスの設定で変更できます。支援によるアプリ機能の解放はありません。支援の記録と、メッセージへの返信のためだけに使用します。
- **Google Play の統計。** Google は、利用状況と診断情報を Google と共有することを選択した利用者のクラッシュ報告など、インストール数や安定性の集計情報を提供する場合があります。不具合の発見と修正だけに使用します。
- **GitHub からのダウンロード。** ブラウザーまたはアプリの更新機能で GitHub からダウンロードする場合、GitHub のプライバシーステートメントが適用されます。

## Vesqen のウェブサイト

vesqen.sumirenokai.com は Cloudflare がホストしています。アカウント、フォーム、広告はなく、アプリが読むバージョンファイルと状態ファイルも配信します。

- **サイトの配信。** ページやファイルの配信と不正利用の防止のため、Cloudflare は IP アドレス、ブラウザー情報、ページのアドレスなどのリクエスト情報を処理します。当方に代わって処理し、同社のポリシーに従って自社サービスの保護にも使用する場合があります。国・地域別のリクエスト数などの集計と、後述する抽出記録が当方に表示されます。訪問者の識別には使用しません。
- **言語の選択。** ホームページは、ブラウザーの言語設定に基づいて英語、簡体字中国語、繁体字中国語、日本語を選択します。判断できない場合は、Cloudflare が IP アドレスから推定した国・地域を使用します。訪問ごとに確認し、結果は保存しません。
- **訪問統計。** Cloudflare Web Analytics で訪問数を集計します。各ページの小さなスクリプトが、ページのアドレス、参照元、読み込み速度を報告し、Cloudflare が国・地域とブラウザー・端末の種類を追加します。Cookie は使わず、ブラウザーに何も保存しません。当方が閲覧できるのは集計値のみで、最大 6 か月間表示されます。EU、欧州経済領域、英国の Cloudflare データセンターを経由する訪問は計測しません。
- **Cookie。** 初回訪問時に言語の記憶を許可するか尋ねます。最大 2 個を設定し、いずれもトラッキングには使用しません。

| Cookie | 目的 | 保存期間 |
| --- | --- | --- |
| `vesqen-consent` | Cookie の許可・拒否を記憶し、繰り返し尋ねないようにします。 | 6 か月 |
| `vesqen-lang` | 選択言語を記憶します。許可した場合にのみ設定します。 | 6 か月 |

各ページ下部の「Cookie 設定」で回答を変更できます。拒否すると `vesqen-lang` を削除します。自動アクセスではないか Cloudflare が確認する際には、`__cf_bm` や `cf_clearance` などのセキュリティ Cookie を設定する場合があります。これらはサービスの運用に必要で、追跡には使用しません。アプリとサイトは他のサイトやアプリをまたいで追跡しないため、ブラウザーの Do Not Track 設定で動作は変わりません。

## サービス提供者と国外での処理

| 提供者 | Vesqen に対する役割 | 所在地 |
| --- | --- | --- |
| Cloudflare, Inc. | サイト、統計・レポートサービス、バージョンファイルのホストとメール転送 | 米国、および世界各地のデータセンター |
| Microsoft Corporation | メールボックスの保存 | 米国およびその他の国 |
| GitHub, Inc. | 同社のプライバシーステートメントに従ったアプリのダウンロード配信 | 米国 |

Cloudflare は、サイト、統計・レポートサービス、メール転送のサービス提供者です。EU–US データプライバシーフレームワーク、その英国拡張、Swiss–US データプライバシーフレームワークの認証を受け、処理条件には EU 標準契約条項も含まれます。本ポリシーの情報は、米国など居住国以外で処理される場合があります。必要とする機能を利用したときだけ暗号化通信で各提供者に届き、連絡先は各社のポリシーに記載されています。希望しない場合は統計とアップデートの自動確認を無効にし、レポートをアップロードしないでください。再生とライブラリは引き続き利用できます。

**Cloudflare のリクエスト記録。** サイトと統計・レポートサービスの各リクエストは Cloudflare が処理します。当方の管理画面には抽出した記録が最大 31 日間表示されます。時刻、IP アドレス、要求したドメインとパス、ブラウザーまたはアプリの種類、推定した国・地域と、その記録から作成した集計が含まれます。サービス保護にも使用し、同じ IP アドレスから 10 秒以内に 5 回を超える統計・レポートのリクエストがあると、10 秒間遮断します。当方は運用維持と不正利用対応のためだけに閲覧し、統計、レポート、メールと照合せず、本人の識別にも使用しません。

## 保存期間と削除

| 情報 | 保存期間 |
| --- | --- |
| 端末上のアプリデータ | 利用者が削除するまで |
| 端末上の最近のエラー | 7 日間、最大 100 件 |
| 端末上のクラッシュ詳細 | 7 日間、最大 3 件 |
| 利用統計 | 日別の合計を 90 日間 |
| アップロードしたデバイスレポート | 7 日間 |
| サポートメール | 対応終了後、最大 12 か月 |
| テスター一覧 | テスト終了後、最大 2 か月 |
| サイトの訪問統計 | 当方に最大 6 か月間表示 |
| Cloudflare が抽出したリクエスト記録 | 当方に最大 31 日間表示 |

- **端末上。** 音楽フォルダの登録を解除すると、そのライブラリ記録を削除します。アプリ内でプレイリストやお気に入りも削除できます。全データを削除するには、Android の「設定 → アプリ → Vesqen → ストレージ」からストレージを消去するか、アンインストールしてください。
- **当方のサービス。** 期限が来た統計とレポートは、上記期間の終了から約 1 時間以内に削除します。Cloudflare のデータベースには最大 30 日の時点復元用バックアップがあり、その期間が過ぎると削除済みの記録もバックアップから消去されます。
- **早期削除。** 希望があればメール、テスター一覧の項目、アップロード済みレポートを早めに削除します。

## セキュリティ

- 端末のデータは Android のアプリサンドボックスで保護された専用領域に保存し、本ポリシーに記載する通信だけを送信します。
- すべてのネットワーク通信に HTTPS を使用します。更新は SHA-256 と、インストール済みアプリと同じ鍵で署名されていることを確認してからインストールします。
- 音楽フォルダへのアクセスは読み取り専用です。
- 統計・レポートサービスのデータベースには IP アドレスやリクエストログを書き込みません。Cloudflare 自体の記録は前述の節で説明しています。
- サポート用メールボックスは 2 段階認証で保護しています。
